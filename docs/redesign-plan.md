# CSWORK 改版与 PracHub 内容迁移计划

2026-10-10 起草。目标：界面和信息结构逐步改成 PracHub 风格；在已取得 PracHub 书面授权的前提下，把对方**公开可见**的内容迁移过来。需要付费或登录才能看到的内容暂不迁移。

## 原则

- **逐步上线**：每一步都是独立的 PR → CI → 部署，随时可回滚。新旧页面并存一段时间，老页面不受影响。
- **设计层先行**：新页面统一包在 `.rd` 下，使用 `app/redesign.css` 里的变量和组件（zinc 中性色、emerald 主色、16px 卡片、细边框加极淡阴影、粗体收紧的标题、小号大写徽章）。第一个落地的是评测状态页。
- **内容来源**：
  - 优先请 PracHub 直接提供结构化导出（JSON/CSV）或接口；
  - 拿不到时，只按 sitemap 抓公开页面：限速 ≤1 次/秒，标明 User-Agent，遵守 robots；
  - 不登录，不绕过付费墙，原始 HTML 本地缓存，只抓一次。
- **署名和授权**：按授权约定标注来源（如"内容来源：PracHub"加原文链接）。授权书留档，确认它覆盖以下几点：转载、翻译和改写；具体的内容类型；署名方式；是否要求 canonical 指回原站。
- **语言**：原文是英文。英文原样入库，中文译文按现有 OA 英文翻译流程反向生成，并带校验，逐批补齐。
- **质量**：每批迁移都要过一遍去重、链接改写、计数核对和抽样人工检查，再上线。

## 前置条件（阻塞内容迁移）

1. **磁盘和备份**：服务器只剩约 11G 空间，数据库约 7G，每日备份一直失败。新内容需要建表，建表必须走 `install.sh`，而它会先做一次完整的在线备份，所以要先解决：选择 VACUUM 收缩数据库，或者把备份挪到外部存储。
2. **授权范围确认**：见上文"署名和授权"。另外最好问一下对方能否直接给导出数据，能省掉大部分抓取和解析工作。

## 阶段

### 阶段 0：设计层 + 评测状态页（进行中）
- 共用设计层 `app/redesign.css`。
- 评测状态页 `?view=status`（全站提交，只公开元数据，每 5 秒自动刷新）。

### 阶段 1：题库与公司页改版（用现有数据）
- **题库列表**：
  - 顶部：H1 + 统计行（题数 / 公司数 / 更新日期）；
  - 筛选：角色、类别 chip，公司、难度、轮次下拉；
  - 排序 tab：最热 / 最新；
  - 卡片：公司徽章、难度圆点、标签，以及"N 人做出 / 通过率"（判题数据里已有）。
- **公司枢纽页** `?view=company&c=<slug>`：
  - 统计（题数、难度分布、近 90 天新增）；
  - 这家公司的题目列表和 FAQ；
  - 先用现有的 1270 道 OA 题生成。
- **每题状态**：未看 / 看过 / 已做出，配合提交历史。
- **验收**：新旧题库都能用；移动端可用；接口耗时不倒退。

### 阶段 2：内容模型和导入管道
- **新内容类型**（建表，需要阶段前置条件 1）：

  | 内容类型 | 主要字段 |
  |---|---|
  | 面试题 | 公司、岗位、轮次、类别、难度、职级、题面、公开题解部分、提示 |
  | 面经 | 公司、岗位、轮次、结果、正文、关联题目 |
  | 指南 | 公司 × 岗位 |
  | 概念 | — |
  | 文章 | — |
  | Cheatsheet | 只迁免费小节 |
  | 课程 | 只迁免费课时，并入现有课程系统 |

- **导入管道**：
  - 流程：导出数据或抓取的原始 HTML → 解析为结构化 JSON → 校验（字段齐全、去重、链接改写）→ 按批次入库；
  - 和 OA 题一样，每个批次可以单独发布、单独回滚。
- **编程题**：先只导入题面和公开样例，作为"练习题面"。之后按现有 OA 判题流程，逐批补测试数据，接入在线判题。
- **试点**：先导一家公司（比如 Google）的全部公开内容，核对质量后再批量导入。

### 阶段 3：详情页
- **题目页**：描述 / 题解 / 讨论 / 提交 四个 tab；顶部摘要；分 Part 展示题面；提示可折叠；底部放相关题和"公司 × 类别"链接。
- **面经页**：概览面板（轮次、难度）+ 正文 + "练习这场面试的题目"卡片 + 同公司面经。
- **指南、概念页**：带目录和阅读进度，统计卡，FAQ，相关链接。

### 阶段 4：让搜索引擎抓得到
- 现在首页只返回"正在加载…"，搜索引擎基本抓不到内容。
- 公开页面改成服务端渲染或预渲染，配语义化 slug、每页独立的 title / description / canonical、JSON-LD（文章 / FAQ / 面包屑）、sitemap，以及 robots。

### 阶段 5：社区与增长（按需）
- 每题讨论区：评论、楼中楼、点赞，带审核。
- 面经投稿 + 审核 + 关联题目。
- 积分（XP）+ 每日任务。
- AI 讲解：选中题面文字提问，按天限额。
- 深色模式。
- 定价页和付费内容：Stripe 尚未配置，放在最后。
