# 仅更新应用代码

`deploy/app-only-release.sh` 用于本次 OA 题库上线：保留数据库、环境变量、systemd 配置、Nginx、语言服务和评测容器，不迁移、不备份数据库，也不清理评测草稿。不能替代常规数据库迁移部署。

调用前必须由发布者核对旧版本到候选版本的完整 Git diff，确认数据库 schema、迁移、启动时数据库操作、评测任务/草稿格式和现有运行配置均兼容。候选构建必须来自该候选提交，并已通过测试、类型检查、生产构建和真实 HTTP 检查。脚本不会自行证明 Git diff 或构建的来源。

```bash
sudo bash deploy/app-only-release.sh \
  <当前部署的完整SHA> <候选完整SHA> \
  /home/ubuntu/cswork-build/<已验证的构建目录> /opt/cswork/runtime/node
```

脚本要求线上 Web 和 worker 已启动、队列未暂停、目标版本目录不存在，并预留至少 512 MiB 磁盘空间。复制完整应用和私有 OA 目录后，暂停队列并等待正在评测的提交结束；排空失败只恢复队列，不停止 worker。之后原子切换版本，重启 Web/worker，检查首页数据及本次启动后的健康心跳。成功后恢复队列，旧版本完整保留。

失败会回切旧版本并检查健康；回滚无法确认健康时维持队列暂停并报错，需要人工处理。正常运行中的程序仍可能写入业务数据和 worker 心跳；“不改数据库”指不执行部署迁移或直接修改数据，并非停止全部业务写入。不要并行运行其他部署工具；锁仅防止该脚本自身重复执行。

部署后核对新版本 `REVISION`、登录后 OA 列表/题解、匿名访问拒绝及私有目录 404，再检查原有算法题单和评测队列。脚本失败或中断留下的候选版本目录保留供排查，不自动删除任何发布目录。
