# 工单附件空间

每个附件最大 2 MiB，每个工单最多 10 个附件。`ATTACHMENTS_MAX_BYTES` 限制全站附件总量，默认 `1073741824`（1 GiB）；设置为 `0` 会停止新附件上传。该值必须是非负整数。

上传在 SQLite 中原子预留容量后才写文件，同时检查当前磁盘并保留至少 3 GiB 空间。容量不足返回 HTTP 507；不会持有覆盖慢速上传请求的全局锁。删除附件会释放配额，其他人的工单无法访问或删除。

磁盘空间检查将已登记附件也计入保守预算，接近磁盘预留线时可能提前停止上传。请通过老师工单界面删除不再需要的附件，并使用部署备份策略保存需要留档的内容。
