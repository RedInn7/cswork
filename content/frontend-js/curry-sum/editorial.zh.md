**思路**：让「当前总和」作为参数传下去，每次返回一个**新**的函数：

```js
function sum(a) {
  return (b) => (b === undefined ? a : sum(a + b));
}
```

- 不带参数时返回 `a`；带参数时递归调用 `sum(a + b)`，得到一个记着新总和的函数。
- 不要把总和存在函数外的变量里，或者挂在函数属性上不断修改。那样 `s(3)` 会把 `s` 也改掉，题目里的复用就出错了。
- 判断用 `b === undefined`，不能用 `!b`，否则 `sum(1)(0)` 会被当成结束。

变种题：`sum(1)(2)(3) == 6`，用隐式类型转换（`valueOf` / `Symbol.toPrimitive`）来实现，最后不需要空调用。面试时能说出两种写法的区别就好。
