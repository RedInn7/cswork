实现 `deepEqual(a, b)`：判断两个值是否「结构相等」。

- 原始值用 `===` 比较，但 `NaN` 与 `NaN` 相等。
- 数组：长度相同，并且每个位置都深度相等。
- 普通对象：自身可枚举的键集合相同（与顺序无关），每个键对应的值深度相等。
- `Date`：时间戳相同才相等。
- 类型不同就不相等：数组不等于有 `0`、`1` 等键的对象；`null` 不等于 `{}`。
- 不需要处理循环引用、`Map`、`Set`。

```js
deepEqual({ a: [1, 2], b: { c: 3 } }, { b: { c: 3 }, a: [1, 2] }); // true
deepEqual([1, 2], { 0: 1, 1: 2, length: 2 });                      // false
deepEqual(NaN, NaN);                                               // true
```
