实现 `uniqBy(array, iteratee)`：按 `iteratee` 算出的键去重，每个键只保留**第一次**出现的元素，顺序不变。

- `iteratee` 可以是函数（接收元素，返回键），也可以是字符串（取元素的这个属性作为键）。
- 键的比较方式与 `Set` 相同：`NaN` 等于 `NaN`，对象按引用比较。
- 返回新数组，不改动原数组。

```js
uniqBy([2.1, 1.2, 2.3], Math.floor);              // [2.1, 1.2]
uniqBy([{ id: 1 }, { id: 2 }, { id: 1 }], 'id');  // [{ id: 1 }, { id: 2 }]
```
