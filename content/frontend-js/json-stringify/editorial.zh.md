**思路**：写一个递归的 `write(key, value)`，返回这个值的 JSON 文本，「应该跳过」时返回 `undefined`。上一层根据返回值决定怎么处理：

- 对象中：返回 `undefined` 就不输出这个属性；
- 数组中：返回 `undefined` 就输出 `null`（`write(...) ?? 'null'`）；
- 最外层：直接返回 `undefined`。

细节：
1. 先检查 `toJSON`，把它的返回值当作新的 `value` 继续处理，`Date` 就是这样变成字符串的。
2. 数字用 `Number.isFinite` 判断，`NaN` 和 `±Infinity` 输出 `null`；`String(-0)` 是 `'0'`，与原生一致。
3. 字符串转义用一条正则 `/["\\\u0000-\u001f]/g`，有简写的用简写，其余写成 `\u00xx`。
4. 循环检测用一个「当前路径」栈：进入对象时压栈，离开时弹出。只有出现在**当前路径**上才算循环，同一个对象在两个分支里各出现一次不算（最后一个测试）。用一个只增不减的「见过的集合」会误报。

原生的 `JSON.stringify` 还处理 `replacer`、`space`、包装对象（`new Number(1)`）和孤立代理项的转义。
