**思路**：路径的处理和 `get` 相同，先变成键数组。然后走到**倒数第二层**，最后一个键直接赋值。

往下走的每一步：
- 下一层是对象或数组（`typeof === 'object'` 且不为 `null`），就直接进去；
- 否则新建一层：看**下一个键**是不是 `/^\d+$/` 这样的非负整数，是就建数组，否则建对象。

```js
if (next === null || typeof next !== 'object') current[key] = /^\d+$/.test(keys[i + 1]) ? [] : {};
```

- 数组路径里的键可能是数字，先用 `String` 统一成字符串，再用正则判断。
- `'-1'`、`'1x'` 不是数组下标，所以要用整串匹配的正则，不能用 `!isNaN(key)`。

**安全提醒**：路径来自用户输入时，要拒绝 `__proto__`、`constructor`、`prototype` 这几个键，否则 `set({}, '__proto__.isAdmin', true)` 会污染所有对象的原型（原型污染漏洞）。
