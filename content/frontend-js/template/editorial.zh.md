**思路**：一个全局正则加上 `replace` 的回调：

```js
template.replace(/\{\{\s*([\w$.]+)\s*\}\}/g, (_, path) => /* 按路径取值 */);
```

- `\{\{` 和 `\}\}` 只匹配成对的双花括号；`\s*` 允许内侧有空格；`([\w$.]+)` 捕获路径。
- 回调里按 `.` 逐层取值，途中遇到 `null` 或 `undefined` 就停。最终值为空时返回 `''`，否则 `String(value)`。不要写 `value || ''`，那样 `0` 和 `false` 也会变成空。
- `replace` 只扫描一遍原字符串，替换进去的内容不会再被匹配，所以值里的 `{{b}}` 不会被二次渲染。
- 替换参数用**函数**而不是字符串：字符串形式的替换参数里，`$&`、`$1` 有特殊含义，值里恰好有这些字符就会出错（最后一个测试）。

真实的模板引擎还要做 HTML 转义，防止 XSS：把用户数据插进页面前，至少要转义 `<`、`>`、`&`、`"`、`'`。
