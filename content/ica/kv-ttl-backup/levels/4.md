Back the store up and restore it to an earlier point in time.

| Method | Returns |
| --- | --- |
| `backup(timestamp)` | saves a backup of the store as it is now and returns how many keys it holds |
| `restore(timestamp, backup_time)` | `True` after restoring the latest backup taken at or before `backup_time`; `False` if there is none, and then nothing changes |

- A backup holds the live keys only, each with its value and, if it expires, the time it had **left** when the backup was taken.
- Restoring replaces the whole store with the backup: keys put later are gone. A restored key that expires gets its remaining time again, counted from the restore's `timestamp`. Keys without expiry stay without expiry.
- Backups are kept after a restore, and the same backup can be restored again later.

Public tests: `tests/test_level4.py`.
