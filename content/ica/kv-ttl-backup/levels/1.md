Build an in-memory key-value store: class `Store` in `src/store.py`. Every method takes a `timestamp` first, an integer that strictly increases from one call to the next. Keys and values are strings (a value may be empty).

| Method | Returns |
| --- | --- |
| `put(timestamp, key, value)` | stores `value` under `key`; returns the value it replaced, or `None` if the key was absent |
| `get(timestamp, key)` | the value, or `None` if the key is absent |
| `delete(timestamp, key)` | `True` after removing the key; `False` if it was absent |

The public tests of this level are `tests/test_level1.py`; the judge also runs hidden tests. Pass them all to unlock level 2. Leave the later levels' methods in the class: their briefs come with them.
