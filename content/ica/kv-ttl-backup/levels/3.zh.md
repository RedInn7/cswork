键可以设置过期时间。

| 方法 | 返回 |
| --- | --- |
| `put_ttl(timestamp, key, value, ttl)` | 与 `put` 相同，并且键在 `timestamp + ttl` 时刻过期（`ttl ≥ 1`） |
| `ttl_left(timestamp, key)` | 距离过期还剩多少时间；没有过期时间的键返回 `-1`；键不存在返回 `None` |

- 在 t 时刻以 ttl = d 写入的键，在 t … t + d − 1 时刻存在，从 t + d 时刻起消失。
- 过期的键对**所有**方法都视为不存在：`get` 返回 `None`，`delete` 返回 `False`，扫描和计数跳过它，在它上面 `put` 或 `put_ttl` 时返回的旧值是 `None`。
- 普通 `put` 写入的键没有过期时间，即使原来的键有。对仍存在的键 `put_ttl` 会替换它的过期时间。

公开测试：`tests/test_level3.py`。
