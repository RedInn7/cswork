Keys can now expire.

| Method | Returns |
| --- | --- |
| `put_ttl(timestamp, key, value, ttl)` | like `put`, and the key expires at `timestamp + ttl` (`ttl ≥ 1`) |
| `ttl_left(timestamp, key)` | the time left before the key expires; `-1` for a key without expiry; `None` if the key is absent |

- A key put at time t with ttl d exists at times t … t + d − 1 and is gone from t + d on.
- An expired key is absent for **every** method: `get` returns `None`, `delete` returns `False`, scans and counts skip it, and a `put` or `put_ttl` over it returns `None` as the replaced value.
- A plain `put` stores a key without expiry, even over a key that had one. A `put_ttl` over a live key replaces its expiry.

Public tests: `tests/test_level3.py`.
