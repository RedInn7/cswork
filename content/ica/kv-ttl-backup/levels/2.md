Look keys up by prefix.

| Method | Returns |
| --- | --- |
| `scan(timestamp, prefix)` | `"<key>=<value>"` for every key that starts with `prefix`, sorted by key in ascending string order |
| `count(timestamp, prefix)` | how many keys start with `prefix` |

- Prefixes are case-sensitive; a key equal to the prefix matches it. The empty prefix matches every key.
- String order compares characters by code point, so `"Apple"` comes before `"app"` and `"user:10"` before `"user:2"`.

Public tests: `tests/test_level2.py`. The hidden tests of level 1 run again with this level's.
