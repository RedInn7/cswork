转账可以预约在以后执行。

| 方法 | 返回 |
| --- | --- |
| `schedule_transfer(timestamp, source_id, target_id, amount, delay)` | 返回 id `"transfer<k>"`，k = 1, 2, … 是本账本成功预约的次数；任一账户不存在或两个 id 相同时返回 `None` |
| `cancel_scheduled(timestamp, source_id, transfer_id)` | 该转账存在、由 `source_id` 预约且尚未执行时，取消它（以后不再执行）并返回 `True`；否则返回 `False` |

- `delay ≥ 1`，转账在 `timestamp + delay` 时刻到期。预约时不检查转出方余额。
- **每次**调用开始时，先执行所有到期时刻不晚于本次 timestamp 的预约转账：到期早的先执行，到期时刻相同的按预约先后执行。
- 到期的转账若此时转出方余额不少于 `amount` 就转账，否则作废。无论哪种，之后都不能再取消。
- 执行成功的预约转账计入转出方的流出总额（第 2 关）。
- 因此在时刻 t 到期的转账，在时刻 t 的调用开始时就已执行：在 t 时刻取消它返回 `False`。
