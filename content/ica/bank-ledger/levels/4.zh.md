账户可以合并，也可以查询历史余额。

| 方法 | 返回 |
| --- | --- |
| `merge(timestamp, keep_id, absorb_id)` | 把 `absorb_id` 并入 `keep_id` 后返回 `True`；任一账户不存在或两个 id 相同返回 `False` |
| `balance_at(timestamp, account_id, time_at)` | 账户在 `time_at` 时刻的余额（`time_at ≤ timestamp`），否则 `None` |

**合并**

- `keep_id` 的余额和流出总额分别加上 `absorb_id` 的。
- `absorb_id` 不再存在：涉及它的调用返回 `None` 或 `False`，不再参与排名，这个 id 以后也不能再开户。
- 尚未执行、涉及 `absorb_id` 的预约转账改为涉及 `keep_id`（之后要用 `keep_id` 取消）。两个账户之间尚未执行的预约转账直接取消。

**历史余额**

- T 时刻的余额 = 所有发生在 ≤ T 时刻的变动之后的余额。预约转账发生在它的到期时刻，尽管它是在之后某次调用开始时才执行的。
- 开户之前：`None`。
- `keep_id` 在合并时刻之前：它自己当时的余额；从合并时刻起：包括并入的部分。
- `absorb_id` 在合并时刻之前：**它自己当时的余额**，就像没有被合并过；从合并时刻起：`None`。
