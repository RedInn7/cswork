Files now belong to users with storage quotas.

| Method | Returns |
| --- | --- |
| `add_user(timestamp, user_id, quota)` | `True` after creating the user; `False` if the user exists or `user_id` is `"admin"` |
| `add_as(timestamp, user_id, path, size)` | adds a file owned by the user and returns the quota they have left; `None` if the user does not exist, the path is taken, or `size` is more than they have left |
| `remaining(timestamp, user_id)` | the quota the user has left, or `None` if the user does not exist |

- A user's quota left = their quota − the total size of the files they own.
- Files added with `add` (level 1) belong to the built-in owner `"admin"`, which has no quota and is not a user: user methods given `"admin"` return `None` or `False`.
- `remove` works on any file and gives its size back to its owner.
- Every file, whoever owns it, still counts in `largest` and `total_size`.

Public tests: `tests/test_level3.py`.
