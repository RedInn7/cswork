实现一个内存文件存储：`src/files.py` 里的 `FileStore` 类。每个方法的第一个参数都是 `timestamp`，是一个整数，每次调用都严格大于上一次。路径是字符串，按原样精确比较（`"/a"`、`"/a/"`、`"/A"` 是三个不同的路径）；大小是 ≥ 0 的整数。

| 方法 | 返回 |
| --- | --- |
| `add(timestamp, path, size)` | 添加文件后返回 `True`；路径已被占用时返回 `False`（什么都不变） |
| `size_of(timestamp, path)` | 文件大小；没有这个文件返回 `None` |
| `remove(timestamp, path)` | 被删除文件的大小；没有这个文件返回 `None` |

本关的公开测试是 `tests/test_level1.py`，评测时还会跑隐藏测试。全部通过后解锁第 2 关。类里后面几关的方法先保留着，说明会随关卡给出。
