Find the largest files under a prefix.

| Method | Returns |
| --- | --- |
| `largest(timestamp, prefix, n)` | up to `n` strings `"<path>(<size>)"` for files whose path starts with `prefix`: larger first, equal sizes by path in ascending string order |
| `total_size(timestamp, prefix)` | the total size of the files whose path starts with `prefix` (0 if none) |

- A prefix is a plain string prefix: `"/a"` matches `"/ab/1"` as well as `"/a/1"`. The empty prefix matches every file.
- String order compares characters by code point: `"/a/10"` comes before `"/a/2"`.

Public tests: `tests/test_level2.py`. The hidden tests of level 1 run again with this level's.
