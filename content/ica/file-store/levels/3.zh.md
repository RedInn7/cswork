文件现在归属于有存储配额的用户。

| 方法 | 返回 |
| --- | --- |
| `add_user(timestamp, user_id, quota)` | 创建用户后返回 `True`；用户已存在或 `user_id` 为 `"admin"` 时返回 `False` |
| `add_as(timestamp, user_id, path, size)` | 添加一个归该用户所有的文件，返回其剩余配额；用户不存在、路径已被占用或 `size` 超过剩余配额时返回 `None` |
| `remaining(timestamp, user_id)` | 用户的剩余配额；用户不存在返回 `None` |

- 剩余配额 = 配额 − 该用户拥有的文件总大小。
- 用 `add`（第 1 关）添加的文件归内置的 `"admin"` 所有：它没有配额，也不算用户，给用户相关方法传 `"admin"` 时返回 `None` 或 `False`。
- `remove` 可以删除任何文件，并把大小还给文件的所有者。
- 不论归谁所有，所有文件都照常计入 `largest` 和 `total_size`。
