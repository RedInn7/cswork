Users can compress their files, and back them up and restore them.

| Method | Returns |
| --- | --- |
| `compress(timestamp, user_id, path)` | replaces the file with `path + ".z"`, of size `⌈size / 2⌉`, and returns the user's quota left; `None` if the user does not exist, the file does not exist or is not theirs, `path` already ends with `".z"`, or `path + ".z"` is taken |
| `backup_user(timestamp, user_id)` | remembers the user's files (paths and sizes) as they are now, replacing any earlier backup, and returns how many there are; `None` if the user does not exist |
| `restore_user(timestamp, user_id)` | puts the user's files back as they were at their backup and returns how many files were restored; `None` if the user does not exist or has no backup |

Restoring first removes every file the user owns now, then adds back each backed-up file — except one whose path is now taken by another owner's file, which is skipped. A file compressed after the backup comes back uncompressed.

Public tests: `tests/test_level4.py`.
