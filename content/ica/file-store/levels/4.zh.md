用户可以压缩自己的文件，也可以备份和恢复。

| 方法 | 返回 |
| --- | --- |
| `compress(timestamp, user_id, path)` | 把文件替换成 `path + ".z"`，大小为 `⌈size / 2⌉`，返回用户的剩余配额；用户不存在、文件不存在或不归该用户、`path` 已经以 `".z"` 结尾，或 `path + ".z"` 已被占用时返回 `None` |
| `backup_user(timestamp, user_id)` | 记下该用户当前所有文件（路径和大小），替换之前的备份，返回文件个数；用户不存在返回 `None` |
| `restore_user(timestamp, user_id)` | 把该用户的文件恢复成备份时的样子，返回恢复的文件个数；用户不存在或从没备份过返回 `None` |

恢复时先删除该用户现在拥有的所有文件，再逐个加回备份里的文件；如果某个路径现在被其他所有者的文件占用，就跳过它。备份之后才压缩的文件，恢复后回到未压缩的状态。
