# 哈希表（拉链法）

用拉链法实现整数到整数的哈希表 `HashMap`：一个桶数组，每个桶是一条存放 (键, 值) 的链表或小数组，键经过哈希函数落到某个桶里。不能用语言自带的哈希表或有序表（`dict`、`set`、`unordered_map`、`map`、`HashMap`、`TreeMap`、Go 的 `map`）。

桶的数量（会被 `buckets` 操作检查）：

- 初始为 8 个桶。
- `put` 新增了一个键之后（更新已有键的值不算），如果 `size * 4 > buckets * 3`，也就是负载因子超过 0.75，桶数**翻倍**，并把所有键值对重新分配到新的桶里。
- 删除不会让桶数变少。

哈希函数自选，只要桶下标落在 `[0, buckets)` 内。

需要实现的方法：

| 方法 | 作用 |
| --- | --- |
| `put(key, value)` | 键不存在就新增，存在就更新值 |
| `get(key)` | 返回键对应的值，键不存在返回 -1 |
| `remove(key)` | 删除键，删除了返回真，键不存在返回假 |
| `size()` | 键值对个数 |
| `buckets()` | 当前桶数 |

## 输入

第一行是操作数 q。接下来 q 行，每行一个操作：

put k v / get k / remove k / size / buckets

1 ≤ q ≤ 2×10^4，|k| ≤ 10^9，0 ≤ v ≤ 10^9。

## 输出

`get` 输出值或 -1；`remove` 删除成功输出 1，否则输出 0；`size` 输出键值对个数；`buckets` 输出桶数。

## 样例说明

前 6 次 put 加入 6 个不同的键：第 7 个新键 put 70 7 之后 size 为 7，7×4 = 28 > 8×3 = 24，桶数翻倍成 16。put 10 100 只是更新值，size 不变。remove 20 成功，再次 remove 20 失败；get 20 得到 -1。

## 提示

- 键可能为负数。像 Java、C++ 这样负数取模会得到负数的语言，要先把哈希值转成非负数。
- 如果直接用 key % buckets，而桶数总是 2 的幂，那么 1024 的倍数在桶数不超过 1024 时会全部挤进同一个桶。先把键乘上一个大奇数（例如 2654435761）打散再取模，能让分布均匀得多。
- 扩容时每个键值对要按新的桶数重新计算下标，不能把旧桶原样搬过去。
