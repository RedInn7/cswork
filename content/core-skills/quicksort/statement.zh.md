# 快速排序

实现快速排序的两个部分：

**1. `partition(a, lo, hi)`：Lomuto 划分。** 以 `a[hi]` 为基准，把区间 `[lo, hi]` 里比基准小的元素换到左边，最后把基准放到它的最终位置并返回这个下标。必须**严格按下面的步骤**做，驱动会检查划分后的数组：

```text
pivot = a[hi]
i = lo
for j = lo .. hi - 1:
    if a[j] < pivot:
        交换 a[i] 和 a[j]
        i = i + 1
交换 a[i] 和 a[hi]
return i
```

**2. `quick_sort(a)`：把整个数组原地排成升序。** 基准怎么选由你决定，但测试里有已经有序和逆序的数组：每次都拿最后一个元素当基准会退化成 O(n²)，递归深度也会达到 n。

不能调用语言自带的排序。函数名按各语言惯例书写（Java 的 `quickSort`、Go 的 `QuickSort`），以起始代码为准。驱动先对数组的一份副本调用一次 `partition(b, 0, n - 1)`，输出返回值和划分后的副本，再对原数组调用 `quick_sort` 并输出结果。

## 输入

第一行是 n，第二行是 n 个**互不相同**的整数。

1 ≤ n ≤ 10^4，所有数的绝对值不超过 10^9。

## 输出

三行：第一行是 partition 返回的下标；第二行是划分后的副本；第三行是排好序的数组。数字之间以空格分隔。

## 样例说明

a = [3, 8, 1, 9, 2, 5]，基准是 5。j 扫过 3（小于 5，与自己交换，i 变 1）、8（不动）、1（与 8 交换，i 变 2）、9（不动）、2（与 8 交换，i 变 3），得到 [3, 1, 2, 9, 8, 5]；最后交换 a[3] 和基准，得到 [3, 1, 2, 5, 8, 9]，返回 3。

## 提示

- 每次划分前随机选一个下标，和 a[hi] 交换后再调用 partition，期望复杂度就是 O(n log n)。
- 先递归处理较短的一边、较长的一边用循环继续，递归深度最多 O(log n)。Python 的默认递归深度只有 1000。
- 基准落定后，它左边的都比它小、右边的都比它大，下一轮只需要处理 [lo, p - 1] 和 [p + 1, hi]。
