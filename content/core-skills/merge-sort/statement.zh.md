# 归并排序与逆序对

实现归并排序 `merge_sort(a)`：把数组原地排成升序（可以用辅助数组），并返回数组里**逆序对**的个数——满足 i < j 且 a[i] > a[j] 的下标对 (i, j) 的数量。相等的两个元素不算逆序对。

逆序对可以在归并时顺便数出来：合并左右两个已排好序的半段时，每当右半段的元素先于左半段剩下的元素被放进结果，左半段还剩几个元素，就多了几个逆序对。整个过程是 O(n log n)。

不能调用语言自带的排序。函数名按各语言惯例书写（Java 的 `mergeSort`、Go 的 `MergeSort`），以起始代码为准。

## 输入

第一行是 n，第二行是 n 个整数。

1 ≤ n ≤ 2×10^4，所有数的绝对值不超过 10^9。

## 输出

两行：第一行是逆序对个数，第二行是排好序的数组（以空格分隔）。

## 样例说明

[3, 1, 2, 3, 0] 的逆序对有 (3, 1)、(3, 2)、(3, 0)、(1, 0)、(2, 0)、(3, 0)，共 6 个；两个 3 相等，不算。

## 提示

- 合并时左右两边的当前元素相等，要先取左边的：这样相等元素不会被算成逆序对，排序也是稳定的。
- 逆序对最多有 n(n - 1) / 2 个。n = 2×10^4 时约 2×10^8，还在 32 位整数范围内，但 n 到 10^5 就会溢出，习惯上用 64 位整数计数。
- 自顶向下递归写最直观；也可以自底向上，从长度 1 的段开始两两合并，长度每轮翻倍。
