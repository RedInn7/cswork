# Kruskal 最小生成树

一张 n 个点、m 条**无向边**的带权图，边按输入顺序编号 1 到 m。实现 `kruskal(n, edges)`：用 Kruskal 算法求最小生成树，返回**按选中先后顺序**排列的边下标（从 0 开始）。

Kruskal 算法：把边按权重从小到大排序（**权重相同的按输入顺序**），依次考虑每条边：如果它连接的两个点当前不在同一个连通块里，就选中它并合并这两个连通块；否则跳过（选它会成环）。判断「是否在同一个连通块」用并查集。

驱动根据返回的边算出总权重：选中的边不足 n - 1 条说明图不连通，输出 -1。排序可以用语言自带的。函数名按各语言惯例书写（Go 的 `Kruskal`），以起始代码为准。

## 输入

第一行是 n 和 m。接下来 m 行，每行三个整数 u v w，表示连接 u 和 v、权重为 w 的无向边（可能有重边和自环）。

1 ≤ n ≤ 10^4，0 ≤ m ≤ 2×10^4，1 ≤ w ≤ 10^6。

## 输出

图连通时输出两行：第一行是最小生成树的总权重，第二行是选中的边的编号（从 1 开始，按选中的先后顺序，以空格分隔；n = 1 时这一行为空）。图不连通时只输出 -1。

## 样例说明

边按权重排好后是：边 3（权重 1）、边 2 和边 5（权重都是 2，按输入顺序先边 2）、边 1（3）、边 4（4）。选边 3 连起 1 和 3；选边 2 连起 2 和 3；边 5 连接 1 和 2，它们已经连通，跳过；选边 1 连起 3 和 4。共 3 条边，总权重 1 + 2 + 3 = 6。

## 提示

- 并查集用路径压缩加按秩（或按大小）合并，单次操作几乎是常数时间；整个算法的瓶颈是 O(m log m) 的排序。
- 排序时把边的下标一起带上，或者对下标数组排序，这样才能返回原来的编号。
- 选够 n - 1 条边就可以提前结束。
