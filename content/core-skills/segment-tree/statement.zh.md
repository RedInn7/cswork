# 线段树：区间和与单点修改

给一个长度为 n 的整数数组，实现线段树 `SegmentTree(values)`，支持：

| 方法 | 作用 |
| --- | --- |
| `update(i, x)` | 把第 i 个元素改成 x |
| `query(l, r)` | 返回第 l 到第 r 个元素（含两端）的和 |

方法里的下标从 0 开始；输入中的下标从 1 开始，由驱动换算。两个操作都要做到 O(log n)。

线段树的每个节点保存一段区间的和：根是整个数组，左右孩子各管一半，叶子是单个元素。修改时从叶子一路更新到根；查询时把 [l, r] 拆成 O(log n) 个完整节点的区间相加。

数组写法有两种，都可以：递归版用 `4n` 大小的数组，节点 k 的孩子是 2k 和 2k + 1；迭代版用 `2n` 大小，叶子放在 `n .. 2n - 1`，节点 k 的父亲是 k / 2。

## 输入

第一行是 n 和 q，第二行是 n 个整数。接下来 q 行，每行一个操作：

set i x / sum l r

1 ≤ n, q ≤ 2×10^4，1 ≤ i ≤ n，1 ≤ l ≤ r ≤ n，所有数的绝对值不超过 10^9。

## 输出

每个 sum 输出一行区间和。

## 样例说明

数组是 [5, -2, 7, 1, 3]。sum 1 3 = 5 - 2 + 7 = 10；set 2 4 后数组变成 [5, 4, 7, 1, 3]，sum 1 3 = 16，sum 2 5 = 15，sum 4 4 = 1。

## 提示

- 和最大可达 2×10^4 × 10^9 = 2×10^13，超过 32 位整数，要用 64 位整数。
- 迭代版查询：l += n、r += n + 1，然后在 l < r 时，l 是右孩子就取 tree[l] 并 l++，r 是右孩子就 r-- 并取 tree[r]，再同时除以 2。
- 如果数组从不修改，前缀和就够了；线段树的价值在于修改和查询都是 O(log n)。
