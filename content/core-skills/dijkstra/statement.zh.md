# Dijkstra 最短路

一张 n 个点、m 条**有向边**的图，边权非负。实现 `dijkstra(n, edges, s)`：返回从起点 s 到每个点的最短距离，到不了的点记为 -1。

Dijkstra 算法：起点距离为 0，其余为无穷大。每次从还没确定的点里取出**距离最小**的那个，它的距离就确定了；再用它的出边去更新（松弛）邻居的距离。边权非负保证了「当前最小的不会再被更新得更小」。

用最小堆存 (距离, 点)：一个点的距离变小时把新的二元组压进堆，旧的留在堆里；弹出时如果它的距离已经比记录的大，说明是过期的，直接跳过（「懒删除」）。总复杂度 O((n + m) log m)。可以用语言自带的优先队列。函数名按各语言惯例书写（Go 的 `Dijkstra`），以起始代码为准。

## 输入

第一行是 n、m 和 s。接下来 m 行，每行三个整数 u v w，表示一条从 u 到 v、权重为 w 的有向边（可能有重边和自环）。

1 ≤ n ≤ 10^4，0 ≤ m ≤ 2×10^4，1 ≤ s ≤ n，0 ≤ w ≤ 10^6。

## 输出

一行 n 个整数：从 s 到点 1、2、……、n 的最短距离，到不了的输出 -1。

## 样例说明

从 1 出发：直接走 1→2 要 4，走 1→3→2 只要 1 + 2 = 3；1→3→2→4 是 3 + 1 = 4，比 1→3→4 的 1 + 5 = 6 短。点 5 只有出边、没有入边，到不了。

## 提示

- 距离可能达到 10^6 × 10^4 = 10^10，超过 32 位整数，要用 64 位整数。
- 边权为 0 也没问题，但如果有负权边，Dijkstra 就不再正确，要换 Bellman-Ford。
- 不要在点第一次入堆时就把它标记为已确定：只有它从堆里弹出（并且不是过期记录）的那一刻，距离才确定。
