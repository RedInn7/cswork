# KMP 字符串匹配

用 KMP 算法在文本 t 里找出模式串 p 的所有出现位置，分两步实现：

**1. `prefix_function(p)`：前缀函数。** `pi[i]` 是 `p[0..i]` 这个前缀里，**既是真前缀又是后缀**的最长子串的长度（真前缀不能是整个串本身）。例如 p = `abab`，pi = [0, 0, 1, 2]。

**2. `find_all(t, p)`：匹配。** 用前缀函数在 O(|t| + |p|) 时间内找出 p 在 t 中所有出现的起始下标（从 0 开始，可以重叠），按从小到大返回。失配时不回退文本指针，只把模式指针跳到 `pi[j - 1]`。

不能调用语言自带的字符串查找（`str.find`、`in`、`string::find`、`indexOf`、`strings.Index`、正则表达式等）。函数名按各语言惯例书写（Java 的 `prefixFunction`、Go 的 `PrefixFunction`），以起始代码为准。

## 输入

两行：第一行是文本 t，第二行是模式串 p，都只由小写字母组成。

1 ≤ |p| ≤ |t| ≤ 3×10^4。

## 输出

三行：第一行是 p 的前缀函数（以空格分隔）；第二行是出现次数；第三行是所有出现的起始下标（以空格分隔），没有出现时输出 -1。

## 样例说明

p = aba 的前缀函数是 [0, 0, 1]：前缀 aba 里，a 既是真前缀又是后缀。t = abababa 中 aba 出现在下标 0、2、4，三次出现互相重叠。

## 提示

- 求前缀函数时，pi[i] 从 pi[i - 1] 出发：p[i] 与 p[j] 相等就 j + 1；不等就让 j = pi[j - 1] 再试，直到 j = 0。
- 匹配和求前缀函数是同一段逻辑：把文本的字符一个个喂给模式指针 j，j 等于 |p| 时就找到一次，然后 j = pi[j - 1] 继续，以便找到重叠的出现。
- 另一种写法是对 p + '#' + t 求一次前缀函数，值等于 |p| 的位置就是匹配的结尾。
