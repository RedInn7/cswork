# 网格 BFS 最短路

一张 R 行 C 列的网格地图：`.` 是空地，`#` 是墙，`S` 是起点，`T` 是终点（各恰好一个）。每一步可以走到上、下、左、右相邻的非墙格子，不能走出地图。实现 `shortest_path(grid)`，返回从 S 到 T 最少要走几步，走不到返回 -1。

每一步的代价都是 1，所以用**广度优先搜索**：从 S 出发一层一层向外扩展，第一次到达某个格子时走过的步数就是到它的最短距离。用队列存待扩展的格子，并记录每个格子是否已经访问过（或者它的距离）。

队列可以用语言自带的（`collections.deque`、`std::queue`、`ArrayDeque`），也可以用数组加头指针。

## 输入

第一行是 R 和 C。接下来 R 行，每行是长度为 C 的字符串。

1 ≤ R, C ≤ 300，地图里恰好有一个 S 和一个 T。

## 输出

一个整数：最少步数，走不到时输出 -1。

## 样例说明

S 在左上角，T 在右下角。可以沿第一行走到最右再一路向下，也可以从左侧绕过墙，两条路线都是 8 步，没有更短的走法。

## 提示

- 格子在**入队时**就标记为已访问，而不是出队时，否则同一个格子会被重复入队很多次。
- 把 (r, c) 编码成 r * C + c，就可以用一维数组记录距离。
- 四个方向写成数组 dr = [1, -1, 0, 0]、dc = [0, 0, 1, -1]，循环处理，比写四段 if 不容易出错。
