# 计数排序

有 n 条记录，第 i 条（从 0 开始）的键是 `keys[i]`，键的取值范围是 `[0, k)`。实现**稳定**的计数排序 `counting_sort(keys, k)`：返回记录下标的一个排列，按键从小到大排列，键相同的记录保持原来的先后顺序。

计数排序不比较元素，分三步，总共 O(n + k)：

1. 数一数每个键出现了多少次，得到 `count[0..k-1]`；
2. 求前缀和，算出每个键在结果里的**起始位置** `start[v] = count[0] + … + count[v - 1]`；
3. 从前往后扫一遍记录，把下标 i 放到 `start[keys[i]]` 处，然后让这个位置加一。

不能调用语言自带的排序。函数名按各语言惯例书写（Java 的 `countingSort`、Go 的 `CountingSort`），以起始代码为准。

## 输入

第一行是 n 和 k，第二行是 n 个键。

1 ≤ n ≤ 2×10^4，1 ≤ k ≤ 10^5，0 ≤ keys[i] < k。

## 输出

一行 n 个整数：排序后的记录编号。驱动把函数返回的下标加 1 后输出，也就是记录编号从 1 开始。

## 样例说明

键依次是 2 0 2 1 0。键 0 的记录是第 2、5 条，键 1 是第 4 条，键 2 是第 1、3 条，按原顺序排在各自的位置，得到 2 5 4 1 3。

## 提示

- 第 3 步必须从前往后扫，才能保证稳定。如果改成从后往前，就要先算每个键的结束位置，再往前填。
- 计数数组的长度是 k，而不是 n。k 比 n 大很多时，计数排序的优势就不明显了。
- 基数排序就是从低位到高位反复做稳定的计数排序，稳定性正是它成立的关键。
