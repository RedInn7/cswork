# 动态数组

只用**定长**存储实现一个动态数组 `DynamicArray`：存储一旦分配就不再改变长度（Python 用 `[0] * cap` 创建，C++ 用 `new int[cap]`，Java 用 `new int[cap]`，Go 用 `make([]int, cap)` 且不再 `append`），需要扩容或缩容时申请一块新存储，把元素逐个搬过去。

容量规则（会被 `capacity` 操作检查）：

- 初始容量为 1，长度为 0。
- `push` 或 `insert` 时如果长度已经等于容量，先把容量**翻倍**，再放入新元素。
- `pop` 或 `erase` 删除元素之后，如果容量大于 1 并且长度不超过容量的四分之一（`size * 4 <= capacity`），把容量**减半**一次。

需要实现的方法：

| 方法 | 作用 |
| --- | --- |
| `push(x)` | 在末尾追加 x |
| `pop()` | 删除并返回最后一个元素 |
| `get(i)` / `set(i, x)` | 读 / 写下标 i（从 0 开始）的元素 |
| `insert(i, x)` | 把 x 插到下标 i，原来 i 及之后的元素后移一位（`0 <= i <= size`） |
| `erase(i)` | 删除并返回下标 i 的元素，之后的元素前移一位 |
| `size()` / `capacity()` | 当前长度 / 当前容量 |

起始代码已经写好了读输入、调用方法、打印结果的驱动，只需补全类里的方法。

## 输入

第一行是操作数 q。接下来 q 行，每行一个操作：

push x / pop / get i / set i x / insert i x / erase i / size / capacity

数据保证每个操作都合法：pop 和 erase 时数组非空，下标都在范围内。

1 ≤ q ≤ 2×10^4，|x| ≤ 10^9。insert 与 erase 合计不超过 2000 次，执行它们时数组长度不超过 1000。

## 输出

`pop`、`get`、`erase`、`size`、`capacity` 各输出一行：被删除或读到的元素、长度或容量。

## 样例说明

push 5、push 7 后容量从 1 变 2；再 push 9 时长度 2 等于容量，容量翻倍成 4。insert 1 3 后数组是 [5, 3, 7, 9]，get 1 读到 3。erase 0 删掉 5，pop 删掉 9，剩 [3, 7]，长度 2。之后 pop 两次：剩 1 个元素时 1×4 ≤ 4，容量减半为 2；数组变空时 0×4 ≤ 2，容量再减半为 1。

## 提示

- push 可以写成 insert(size, x)，pop 可以写成 erase(size - 1)，扩容和缩容的逻辑只写一遍。
- 后移元素要从最后一个开始往前搬，否则会覆盖还没搬的值；前移则从前往后搬。
- 为什么缩容要等到四分之一而不是一半？试想容量为 4、长度在 2 和 3 之间来回 push / pop 时会发生什么。
