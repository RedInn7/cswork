# Prim 最小生成树（稠密图）

一张 n 个点的无向带权图用**邻接矩阵**给出：`w[i][j]` 是连接 i 和 j 的边的权重，-1 表示没有边，对角线是 0。实现 `prim(n, w)`：用 O(n²) 的 Prim 算法求最小生成树，返回各个点**加入树的先后顺序**。函数里的点从 0 开始编号（`w` 也是从 0 开始的 n × n 数组），驱动输出时再加 1。

Prim 算法：从点 1（函数里的 0 号点）出发。维护每个树外点的 `key`，即它与树中各点之间最轻的那条边的权重（没有边为无穷大）。每一步把 key 最小的树外点加入树（**key 相同时选编号小的**），再用它的边更新其余树外点的 key。如果剩下的树外点 key 都是无穷大，说明图不连通，停下即可。

稠密图上不用堆：每一步扫一遍所有点找最小 key，共 n 步，正好 O(n²)，与读入邻接矩阵的开销相当。驱动根据返回的顺序算出总权重；返回的点不足 n 个时输出 -1。函数名按各语言惯例书写（Go 的 `Prim`），以起始代码为准。

## 输入

第一行是 n。接下来 n 行，每行 n 个整数，第 i 行第 j 个是 w[i][j]。矩阵对称，w[i][i] = 0，其余为 -1 或 1 到 1000 之间的权重。

1 ≤ n ≤ 200。

## 输出

图连通时输出两行：第一行是最小生成树的总权重，第二行是各点加入树的顺序（以空格分隔，第一个是 1）。图不连通时只输出 -1。

## 样例说明

从 1 出发，key 依次是：2 为 2、3 为 6、4 为 5。加入 2，更新后 3 的 key 变成 3。加入 3（key 3），4 的 key 变成 1。最后加入 4。总权重 2 + 3 + 1 = 6，顺序 1 2 3 4。

## 提示

- 用一个布尔数组标记点是否已在树中，key 初始化为无穷大，key[1] = 0。
- 「key 相同选编号小的」意味着扫描时只在严格更小时才更新最小值。
- 稀疏图上用堆加邻接表的 Prim 是 O(m log n)；稠密图上 m 接近 n²，O(n²) 的版本反而更快。
