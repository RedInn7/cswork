# 拓扑排序（字典序最小）

n 个任务编号 1 到 n，有 m 条先后约束「u 必须排在 v 之前」。实现 `topo_order(n, edges)`：返回满足所有约束的排列里**字典序最小**的那一个；约束之间有环、排不出来时返回空列表。

用 Kahn 算法：统计每个点的入度，把入度为 0 的点放进候选集合；每次从候选集合里取出**编号最小**的点放到结果末尾，把它指向的点的入度减一，减到 0 的点加入候选集合。最后结果里不足 n 个点，说明有环。

候选集合用最小堆，总复杂度 O((n + m) log n)。可以用语言自带的优先队列（`heapq`、`priority_queue`、`PriorityQueue`、`container/heap`），也可以复用「最小堆」那道题的实现。函数名按各语言惯例书写（Java 的 `topoOrder`、Go 的 `TopoOrder`），以起始代码为准。

## 输入

第一行是 n 和 m。接下来 m 行，每行两个整数 u v，表示 u 必须排在 v 之前（u ≠ v，同一条约束可能重复出现）。

1 ≤ n ≤ 10^4，0 ≤ m ≤ 2×10^4。

## 输出

一行：字典序最小的拓扑序（以空格分隔）；有环时输出 -1。

## 样例说明

约束是 3→1、3→2、4→2。开始时入度为 0 的是 3 和 4，先取 3，1 的入度变成 0；此时候选是 1 和 4，取 1；再取 4，2 的入度变成 0；最后取 2。结果是 3 1 4 2。

## 提示

- 用普通队列（先进先出）也能得到一个合法的拓扑序，但不一定是字典序最小的。
- 用邻接表存图：每个点记下它指向的点，重复的边就重复记录，入度也重复计算，二者一致就不会出错。
- 判断有环只需要看最后取出的点数是否等于 n。
