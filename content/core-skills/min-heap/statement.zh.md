# 最小堆

用数组实现二叉最小堆 `MinHeap`：下标 i 的父节点是 `(i - 1) / 2`（向下取整），孩子是 `2i + 1` 和 `2i + 2`，每个节点都不大于它的孩子。不能用语言自带的堆或优先队列（`heapq`、`priority_queue`、`PriorityQueue`、`container/heap`）。

`dump` 操作会按数组顺序输出堆的内部存储，所以必须**严格按下面的步骤**调整：

- `push(x)`：把 x 放到数组末尾，然后**上浮**：只要它比父节点**严格小**，就和父节点交换。
- `pop()`：记下堆顶；把最后一个元素移到下标 0 并删掉末尾，然后**下沉**：在存在的孩子里选值最小的那个（两个孩子相等时选左孩子），只要它比当前节点**严格小**，就交换并继续。返回记下的堆顶。
- `build(values)`：丢弃原来的内容，把 values 原样放进数组，然后从最后一个非叶子节点 `n / 2 - 1` 到 0 依次对每个下标下沉（Floyd 建堆，O(n)）。

需要实现的方法：`push(x)`、`pop()`、`top()`（返回最小值）、`size()`、`build(values)`、`dump()`（返回内部数组的副本）。

驱动只在堆非空时调用 `pop` 和 `top`，堆为空时直接输出 empty。

## 输入

第一行是操作数 q。接下来 q 行，每行一个操作：

push x / pop / top / size / build k a1 a2 … ak / dump

1 ≤ q ≤ 2×10^4，|x|、|ai| ≤ 10^9，所有 build 的 k 之和不超过 2×10^4，dump 输出的数字总数不超过 5×10^4。

## 输出

`pop` 和 `top` 输出最小值，堆为空时输出 empty；`size` 输出元素个数；`dump` 在一行内按数组顺序输出所有元素（以空格分隔），堆为空时输出 empty。

## 样例说明

依次 push 5 3 8 1：1 加入时在下标 3，比父节点 3 小，交换到下标 1，又比堆顶 3 小，交换到下标 0，数组是 [1, 3, 8, 5]。pop 返回 1，把 5 移到堆顶后下沉：孩子 3 和 8 中 3 较小且比 5 小，交换，得到 [3, 5, 8]。build 5 9 4 7 1 2 先放入 [9, 4, 7, 1, 2]，从下标 1 开始下沉：4 的孩子 1 和 2 中 1 最小，交换得 [9, 1, 7, 4, 2]；再处理下标 0：9 与较小的孩子 1 交换后继续下沉，新孩子 4 和 2 中 2 较小，再交换，得到 [1, 2, 7, 4, 9]。

## 提示

- 「相等时选左孩子」「严格小于才交换」这两条规则决定了 dump 的结果，写错一条就会和期望不同。
- pop 之后如果堆变空，不要再对下标 0 下沉。
- 为什么 Floyd 建堆是 O(n)？大多数节点在底部，下沉的距离很短。
