# 并查集（路径压缩 + 按秩合并）

实现并查集 `UnionFind(n)`，管理 n 个点（编号 1 到 n）组成的若干集合，开始时每个点自成一个集合：

| 方法 | 作用 |
| --- | --- |
| `find(x)` | 返回 x 所在集合的代表元（根） |
| `union(a, b)` | 合并 a、b 所在的集合；原来不在同一集合返回真，否则返回假 |
| `same(a, b)` | a、b 是否在同一集合 |
| `size(x)` | x 所在集合的元素个数 |
| `count()` | 当前集合的个数 |

每个集合是一棵树，`parent[x]` 指向父节点，根的父节点是自己。两个优化让每次操作的均摊代价接近常数（反阿克曼函数）：

- **路径压缩**：`find` 时把沿途经过的节点直接挂到根上（或者每隔一个挂到祖父上）；
- **按秩合并**：合并时让较矮（秩较小）或较小的树挂到另一棵下面。

方法名按各语言惯例书写（Go 的 `Union`；`union` 是 C++ 的关键字，C++ 里叫 `unite`），以起始代码为准。

## 输入

第一行是 n 和 q。接下来 q 行，每行一个操作：

union a b / same a b / size x / count

1 ≤ n ≤ 10^5，1 ≤ q ≤ 2×10^4，1 ≤ a, b, x ≤ n。

## 输出

`union` 合并成功输出 1，原本就在同一集合输出 0；`same` 在同一集合输出 1，否则输出 0；`size` 输出集合大小；`count` 输出集合个数。

## 样例说明

5 个点开始时是 5 个集合。union 1 2、union 3 4 后剩 3 个集合；union 2 1 时 1 和 2 已在一起，输出 0。union 1 3 把 {1, 2} 和 {3, 4} 合成大小为 4 的集合，same 2 4 为 1，最后剩 2 个集合。

## 提示

- 只用路径压缩、不按秩合并，最坏情况下单次操作是 O(log n) 均摊；两者都用才是接近常数。
- 按大小合并时顺手维护每个根的集合大小，size 就是 O(α(n))。
- 递归写 find 在很深的树上可能栈溢出；用循环加「路径减半」（parent[x] = parent[parent[x]]）更稳妥。
