# Bellman-Ford 最短路与负环

一张 n 个点、m 条**有向边**的图，边权**可以为负**。实现 `bellman_ford(n, edges, s)`：

- 如果从起点 s 出发能走到一个**负环**（环上边权之和小于 0），最短路没有意义，返回「空」（Python 的 `None`、C++ 的空数组、Java 的 `null`、Go 的 `nil`）；
- 否则返回 s 到每个点的最短距离，到不了的点记为起始代码里定义的常量 `INF`。

Bellman-Ford 算法：起点距离为 0，其余为 INF。把所有边松弛一遍算一轮，最短路最多经过 n - 1 条边，所以 n - 1 轮之后距离一定都正确了。之后再扫一遍所有边，如果还有边能让距离变小，说明有从 s 能到达的负环。

松弛时只从距离不是 INF 的点出发，否则「INF 加负数」会被当成一个可达的距离。函数名按各语言惯例书写（Java 的 `bellmanFord`、Go 的 `BellmanFord`），以起始代码为准。

## 输入

第一行是 n、m 和 s。接下来 m 行，每行三个整数 u v w，表示一条从 u 到 v、权重为 w 的有向边。

1 ≤ n ≤ 500，0 ≤ m ≤ 2000，1 ≤ s ≤ n，|w| ≤ 10^4。

## 输出

如果从 s 能到达负环，输出一行 NEGATIVE CYCLE；否则输出一行 n 个值：s 到点 1、2、……、n 的最短距离，到不了的输出 INF。

## 样例说明

从 1 出发：1→2 是 4，1→3→2 是 5 + (-3) = 2，更短；1→3→2→4 是 2 + 2 = 4。点 5 到不了，输出 INF。

## 提示

- 某一轮没有任何距离变小，就可以提前结束：之后也不会再变。
- 负环必须从 s 能走到才算数。图里别处的负环不影响答案，所以第 n 轮检查同样只看距离不是 INF 的点。
- 复杂度是 O(nm)，比 Dijkstra 慢，换来的是能处理负权边。
