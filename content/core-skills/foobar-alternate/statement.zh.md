# 交替输出

两个线程共用一个 `FooBar` 对象：一个线程调用 `foo(emit)`，另一个调用 `bar(emit)`。两个方法里各自要调用 n 次 `emit`，并且所有调用必须严格交替：foo 先，然后 bar，再 foo，再 bar……一共 2n 次。

两个线程的启动先后是随机的。不要用 `sleep` 去等对方，也不要空转循环检查标志，用信号量、条件变量、channel 这类阻塞原语轮流交出执行权。

| 方法 | 作用 |
| --- | --- |
| `FooBar(n)` | 每一方要调用 emit 的次数 |
| `foo(emit)` | 调用 n 次 emit，每次都等轮到 foo |
| `bar(emit)` | 调用 n 次 emit，每次都等轮到 bar |

驱动会测很多轮，每轮新建一个 `FooBar`，随机决定哪个线程先启动，并在 `emit` 前后随机让出 CPU 或短暂休眠。判题只比较输出，所以绕开线程直接拼出答案也能通过，但那样就没有练到并发。

## 输入

第一行是随机种子 seed 和轮数 R。接下来 R 行，每行是 n 和两个单词：foo 一方的 emit 记录第一个单词，bar 一方的 emit 记录第二个单词。

1 ≤ R ≤ 100，1 ≤ n ≤ 40，0 ≤ seed < 2^31，单词由 1 到 6 个小写字母组成。

## 输出

每轮输出一行：这一轮所有 emit 按调用先后记录下的单词，以空格分隔。

## 样例说明

第一轮 n = 3，foo 一方记 tick，bar 一方记 tock。正确的交替是 tick tock tick tock tick tock。即使 bar 的线程先启动，它也要等 foo 先 emit 一次。

## 提示

- 两个信号量就能表示“轮到谁”：foo 的初值为 1，bar 的初值为 0；每次 emit 之后把执行权交给对方。
- Go 可以用两个容量为 1 的 channel 传递一个“令牌”。
- 用一个条件变量和一个 foo_turn 布尔值也可以：等到轮到自己，emit，翻转 foo_turn，再唤醒对方。
