# 原生参考程序验证链

本次只扩展作者离线验证/发布工具，不修改线上判题引擎或题包。Python旧报告保持兼容；新增C++参考程序必须具有明确referenceLanguage及精确源码指纹。

reference-program统一语言、文件扩展名与源码证据；reference-sandbox统一沙箱内编译、运行及文件回收。C++不能在验证器宿主编译，编译缓存由GoJudge返回并在成功/失败路径finally清理；负控必须正常退出且答案错误，编译/运行异常均不能计为击杀。

验证器和发布器同时检查参考语言属于题目允许提交语言。全流程继续要求唯一公开作者程序、源码与参考文件一致、batch/entry/package/oracle/mutant指纹有效。集成测试按实际参考语言提交正确程序、首例错误及仅背公开样例的错误程序。

验证：51项原生/coverage/发布防篡改测试及6项全题内容证据测试通过；TypeScript检查通过。专用GoJudge 5054真实smoke完成5次编译、6次执行：Python/C++正确、正常退出错误答案、编译错误、运行非零及回调失败均符合预期。返回的4个编译缓存全部删除，并逐个GET确认404。未触碰生产、未生成或伪造正式题目沙箱报告。

独立门禁审阅确认Python旧报告兼容、C++缺失语言证据拒绝、精确源码绑定和发布允许语言检查未被绕过；离线51项独立复跑通过。

这些测试仅证明工具扩展，不代表Amazon83已接入。该题仍需正式题包、独立oracle和Linux沙箱完整规模验证。
