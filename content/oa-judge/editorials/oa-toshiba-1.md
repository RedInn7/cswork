## 思路

对每个数的模 3 余数 r，最少改变量为 `min(r,3-r)`；相加即得答案。独立 oracle 逐步模拟 +1/-1 的可达集合。

## 正确性证明

余数为 0 不需操作；余数为 1 时减一只需一步，余数为 2 时加一只需一步。任何一步至多改变余数到相邻模类，故非零余数至少一步；对所有元素求和即最小总操作数。

## 复杂度

一次操作严格为对一个元素执行 +1 或 -1；数组值可为负数。

O(n) 时间、O(1) 额外空间。

## 参考实现

```python
def solve(raw):
 z=list(map(int,raw.split()));n=z[0];return str(sum(min(x%3,3-x%3) for x in z[1:1+n]))
```
