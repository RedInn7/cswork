# Log Loss：截断后的交叉熵

多分类模型对每个样本输出了 k 个类别的概率。不调 sklearn，实现 `log_loss(y, probs)`，返回平均交叉熵：

- 取出每个样本**真实类别**的预测概率 p，截断到 [ε, 1 - ε]，其中 ε = `EPS` = 10⁻¹⁵。
- 损失是所有样本 -ln p 的平均值。

截断是为了不让一个把真实类别概率给成 0 的样本把损失变成无穷大：截断后它贡献 -ln 10⁻¹⁵ ≈ 34.538776。概率按给定值直接用，**不要重新归一化**。

## 输入

第一行是数据组数 T。每组先是一行 n 和 k，然后 n 行，每行一个真实类别（0 到 k - 1）和 k 个概率。

1 ≤ T ≤ 50，每组 1 ≤ n ≤ 3000，2 ≤ k ≤ 20，所有组的 n·k 之和不超过 5×10^4。

## 输出

驱动代码先输出 T，再输出每组的 log loss，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

第一组三个样本真实类别的概率是 0.9、0.8、0.4，损失 = -(ln 0.9 + ln 0.8 + ln 0.4) / 3 ≈ 0.414932。第二组第一个样本是 -ln 0.5 ≈ 0.693147；第二个样本真实类别的概率是 0，截断成 10⁻¹⁵ 后是 34.538776，平均约 17.615962。

## 提示

- 用花式索引一次取出真实类别的概率：`probs[np.arange(n), y]`。
- `np.clip(p, EPS, 1 - EPS)` 之后再取 `np.log`，就不会出现 log(0) 的警告和 inf。
- 上界截断几乎不影响结果，但下界不能省：一个 0 就会让整组的损失变成 inf。
