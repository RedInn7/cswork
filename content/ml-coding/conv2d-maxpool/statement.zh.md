# 卷积层前向：Conv2D、ReLU 与最大池化

给定一张 H×W 的单通道图像、一个 kh×kw 的卷积核、偏置 b、步长 s 和补零圈数 p。不调 PyTorch，实现卷积网络里最基本的一段前向计算：

- `conv2d(image, kernel, bias, stride, padding)`：先在图像四周补 p 圈 0，再让卷积核每次移动 s 格扫过去，每个位置的输出是**对应元素相乘再求和**，加上偏置。输出大小是 ⌊(H + 2p - kh) / s⌋ + 1 行、⌊(W + 2p - kw) / s⌋ + 1 列。
- `max_pool(x)`：2×2 最大池化，步长 2。行数或列数是奇数时，**最后一行或一列丢掉**。

注意深度学习框架里的「卷积」其实是**互相关**：卷积核不翻转。驱动代码会把 conv2d 的结果过一遍 ReLU（负数变 0）再交给 max_pool。

## 输入

第一行是 H、W、kh、kw、s、p、b。接下来 H 行是图像，再接下来 kh 行是卷积核，都是整数；偏置 b 是实数。

1 ≤ H, W ≤ 64，1 ≤ kh, kw ≤ 5，1 ≤ s ≤ 4，0 ≤ p ≤ 2。数据保证卷积输出至少 2×2。

## 输出

驱动代码先输出数字个数，再依次输出：卷积输出的行数和列数、池化输出的行数和列数、卷积输出（按行展开）、池化输出（按行展开），保留 6 位小数。

## 样例说明

4×4 图像、3×3 拉普拉斯核、p = 1、s = 1，卷积输出仍是 4×4。左上角的位置盖住补出来的 0：上、左是 0，中心 1 乘 -4，右边 2，下边 5，结果 3。第 (1, 1) 个位置中心是 6，上下左右是 2、8、5、7，结果 22 - 24 = -2。ReLU 之后做 2×2 池化，左上块 [3, 2, 0, 0] 取 3，四块的最大值是 [3, 1, 0, 1]。

## 提示

- `np.pad(image, p)` 一次补好四周的 0。
- 输出位置 (i, j) 对应补零后图像里从 (i·s, j·s) 开始的 kh×kw 窗口，`(window * kernel).sum()` 就是这一格。
- 池化可以不写循环：截掉多余的行列后 `reshape(ph, 2, pw, 2).max(axis=(1, 3))`。
