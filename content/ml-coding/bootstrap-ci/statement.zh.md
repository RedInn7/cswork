# 自助法（Bootstrap）置信区间

想知道样本均值有多可靠，又不想假设数据服从正态分布，可以用自助法：从样本里**有放回地**重抽 B 次、每次 n 个，看重抽样均值的分布。不调 scipy，实现 `bootstrap_ci(x, B, level, seed)`，返回 `(样本均值, 标准误, 下界, 上界)`。

随机数用题目给定的线性同余生成器（LCG），不用 `np.random`，答案才唯一：

- state 初始为 seed。每要一个下标，先更新 state ← (1664525·state + 1013904223) mod 2³²，再取下标 ⌊state·n / 2³²⌋。
- 依次生成第 0 次重抽的 n 个下标、第 1 次重抽的 n 个下标……共 B 次，每次重抽的均值记为 m_b。

然后：

- 标准误是 B 个 m_b 的样本标准差（除以 B - 1）。
- 置信区间用**百分位法**：令 q = (1 - level) / 2，下界是 m 的第 q 分位数，上界是第 1 - q 分位数。分位数用线性插值：把 m 从小到大排成 s₀ … s_{B-1}，h = (B - 1)·q，结果是 s_{⌊h⌋} + (h - ⌊h⌋)·(s_{⌊h⌋+1} - s_{⌊h⌋})（这就是 `np.percentile` 的默认算法）。

## 输入

第一行是 n、B、level、seed，第二行是 n 个实数。

2 ≤ n ≤ 200，2 ≤ B ≤ 2000，n·B ≤ 2×10^5，0 < level < 1，0 ≤ seed < 2³²。

## 输出

驱动代码先输出 4，再输出样本均值、标准误、下界、上界，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

x = [1, 2, 3, 4]，seed = 1。第一个 state 是 1664525 + 1013904223 = 1015568748，下标 ⌊1015568748·4 / 2³²⌋ = 0。第 0 次重抽的下标是 [0, 1, 2, 2]，均值 2.25；5 次的均值是 [2.25, 2.5, 2, 3, 3]，标准差约 0.447214。level = 0.6 时 q = 0.2：排序后是 [2, 2.25, 2.5, 3, 3]，h = 4 × 0.2 = 0.8，下界 = 2 + 0.8 × 0.25 = 2.2；上界 h = 3.2，在 3 和 3 之间，是 3。

## 提示

- 一个下标要用**更新后**的 state 算；state·n 最大约 8.6×10^11，Python 整数不会溢出。
- 先生成全部 B·n 个下标，`reshape(B, n)` 后用 `x[idx].mean(axis=1)` 一次算出所有重抽均值。
- 标准误要用 `std(ddof=1)`；numpy 的 `std` 默认除以 B。
