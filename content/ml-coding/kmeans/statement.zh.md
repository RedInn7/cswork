# K-Means：给定初始中心的 Lloyd 迭代

给定 n 个 d 维点和 k 个初始中心。不调 sklearn，实现 `kmeans(X, centers, max_iter)`，按下面的步骤做 Lloyd 迭代，返回 `(最终中心, 每个点的簇编号)`：

1. **分配**：每个点分给离它最近的中心（欧氏距离）。**距离相同时分给下标小的中心。**
2. 重复至多 max_iter 次：
   - **更新**：每个中心移到分给它的点的均值。**没有分到任何点的中心保持原位。**
   - 重新分配。如果没有任何点换簇，停止。
3. 返回最终的中心和最后一次分配的结果（也就是每个点相对于最终中心的归属）。

初始中心由输入给定，不用随机数：结果才可以判对错。驱动代码会用你返回的中心和簇编号算出 inertia（每个点到所属中心的平方距离之和）一起输出。

## 输入

第一行是 n、d、k、max_iter。接下来 n 行是点的坐标，再接下来 k 行是初始中心的坐标，每行 d 个实数。

1 ≤ n ≤ 500，1 ≤ d ≤ 4，1 ≤ k ≤ 8，1 ≤ max_iter ≤ 50。数据保证不会有点到两个不同中心的距离几乎相等（只有完全相同的两个中心才会打平），所以不同写法得到的分配一致。

## 输出

驱动代码先输出数字个数，再依次输出：最终中心（按行展开，k·d 个数）、n 个簇编号、inertia，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

初始中心 (1, 1)、(2, 1)、(20, 20)。第一次分配：(1, 1)、(1, 2) 归 0 号，(2, 1) 和右上角三个点归 1 号，2 号中心 (20, 20) 没有分到点。更新后 0 号移到 (1, 1.5)，1 号移到 (6.75, 6.5)，2 号保持 (20, 20)。重新分配时 (2, 1) 离 0 号更近，换了簇；再更新，两个中心变成 (4/3, 4/3) 和 (25/3, 25/3)，再分配没有变化，停止。inertia = 4/3 + 4/3 ≈ 2.666667。

## 提示

- 用广播一次算出 n×k 的平方距离矩阵，`argmin(axis=1)` 在并列时正好返回下标小的那个。
- 更新时先判断簇是不是空的：对空数组求 `mean` 会得到 NaN 并发出警告。
- 用「分配结果不变」判断收敛，比比较中心的浮点数是否相等更稳妥。
- 最后返回的簇编号要对应最终的中心：即使因为 max_iter 用完而停下，也要先重新分配一次。
