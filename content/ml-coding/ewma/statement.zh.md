# 指数加权移动平均（EWMA）与偏差修正

指数加权移动平均让越近的数据权重越大，监控指标的平滑、Adam 优化器的动量都用它。给定序列 x₁ … xₙ 和平滑系数 α（0 < α ≤ 1），不调 pandas，实现 `ewma(x, alpha)`，返回两个长度为 n 的序列 `(s, v_hat)`：

- **递推 EWMA**：s₁ = x₁，sₜ = α·xₜ + (1 - α)·sₜ₋₁。
- **偏差修正的 EWMA**：v₀ = 0，vₜ = (1 - α)·vₜ₋₁ + α·xₜ，再修正 v̂ₜ = vₜ / (1 - (1 - α)ᵗ)。

从 0 起步的 vₜ 在开头会被拉向 0，除以 1 - (1 - α)ᵗ 正好抵消这个偏差，Adam 里的 m̂ 就是这样算的。两种写法分别等于 pandas 的 `ewm(alpha=α, adjust=False).mean()` 和 `ewm(alpha=α, adjust=True).mean()`。

## 输入

第一行是 n 和 α，第二行是 n 个实数。

1 ≤ n ≤ 10^4，0 < α ≤ 1，所有数的绝对值不超过 10^4。

## 输出

驱动代码先输出 2n，再输出 s₁ … sₙ 和 v̂₁ … v̂ₙ，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

α = 0.5，x = [10, 20, 20, 5]。递推：s = [10, 15, 17.5, 11.25]。偏差修正：v₁ = 5，除以 1 - 0.5 = 0.5 得 10；v₂ = 2.5 + 10 = 12.5，除以 0.75 得 16.666667；v₃ = 16.25，除以 0.875 得 18.571429；v₄ = 10.625，除以 0.9375 得 11.333333。

## 提示

- 递推必须按顺序算，一个循环 O(n) 就够了。
- 不要用 (1 - α)⁻ᵗ 之类的公式把递推展开成向量运算：α 很小、n 很大时会溢出或损失精度。
- α = 1 时两种 EWMA 都等于原序列；(1 - α)ᵗ = 0 不会造成除零。
