# 线性回归：岭回归的闭式解

给定 n 个样本的 d 个特征和目标值 y，以及正则系数 λ ≥ 0。不调 sklearn，用闭式解求权重 w 和截距 b，使下式最小：

Σᵢ (yᵢ - xᵢ·w - b)² + λ·||w||²

**截距 b 不加惩罚**（sklearn 的 `Ridge` 也是这样）。实现 `ridge_fit(X, y, lam)`，返回 `(w, b)`。驱动代码会用你的 w 和 b 算出训练集上的均方误差一起输出。

一种做法：先把 X 的每一列和 y 减去各自的均值，在中心化的数据上解 (XcᵀXc + λI)·w = Xcᵀyc，再由 b = ȳ - x̄·w 求截距。

## 输入

第一行是 n、d、λ。接下来 n 行，每行 d 个特征和一个目标值。

1 ≤ n ≤ 2000，1 ≤ d ≤ 8，0 ≤ λ ≤ 10^5。数据保证 XcᵀXc + λI 可逆且条件数不大。

## 输出

驱动代码先输出 d + 2，再输出 w 的 d 个分量、b、训练集均方误差，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

x = [1, 2, 3]，y = [3, 5, 7]，λ = 2。中心化后 xc = [-1, 0, 1]，yc = [-2, 0, 2]，XcᵀXc = 2，Xcᵀyc = 4，所以 w = 4 / (2 + 2) = 1，b = 5 - 2·1 = 3。不加惩罚时 w 本该是 2，λ 把它往 0 拉了一半。预测值是 4、5、6，均方误差 (1 + 0 + 1) / 3 ≈ 0.666667。

## 提示

- 用 `np.linalg.solve(A, b)` 解线性方程组，比先求 `np.linalg.inv(A)` 再相乘更快也更准。
- 如果把截距写成全 1 的一列放进 X，正则矩阵在这一列对应的对角线位置要是 0，否则截距也被惩罚了。
- λ = 0 就是普通最小二乘。
