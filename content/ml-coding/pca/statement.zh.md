# 主成分分析（PCA）

PCA 找出数据方差最大的几个正交方向，用来降维和去相关。给定 n 个 d 维样本，不调 sklearn，实现 `pca(X, m)`，返回 `(components, ratios)`：

1. 每一列减去它的均值，得到中心化的 Xc。
2. 协方差矩阵 C = XcᵀXc / (n - 1)。
3. 对 C 做特征分解，特征值从大到小排序：λ₁ > λ₂ > …。
4. `components` 是前 m 个特征值对应的**单位**特征向量，按行排成 m×d 矩阵。特征向量乘 -1 仍是特征向量，所以规定**每一行绝对值最大的分量为正**。
5. `ratios` 是前 m 个方差解释比例 λᵢ / (λ₁ + … + λ_d)。

驱动代码还会输出每个样本在这 m 个主成分上的投影 Xc·componentsᵀ。

## 输入

第一行是 n、d、m，接下来 n 行，每行 d 个实数。

2 ≤ n ≤ 300，1 ≤ m ≤ d ≤ 6。数据保证前 m + 1 个特征值互不相同（相差明显），每个主成分里绝对值最大的分量也唯一，所以答案唯一。

## 输出

驱动代码先输出数字个数，再依次输出 components（按行展开）、m 个比例、n×m 的投影（按行展开），保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

均值是 (3, 1.5)，协方差矩阵是 [[20/3, 8/3], [8/3, 5/3]]，特征值约 7.821952 和 0.511381，比例约 0.938634 和 0.061366。第一个特征向量可以算成 (-0.917590, -0.397529)，绝对值最大的分量是负的，所以翻成 (0.917590, 0.397529)；第二个翻成 (-0.397529, 0.917590)。第一个点 (0, 0) 中心化后是 (-3, -1.5)，在第一个主成分上的投影是 -3 × 0.917590 - 1.5 × 0.397529 ≈ -3.349062。

## 提示

- 协方差矩阵是对称的，用 `np.linalg.eigh`：它返回的特征值是**升序**的，要倒过来取；特征向量在返回矩阵的**列**里。
- 也可以对 Xc 做 SVD：右奇异向量就是主成分，奇异值 σ 和特征值的关系是 λ = σ² / (n - 1)。
- 比例的分母是全部 d 个特征值之和，也就是各列方差之和（C 的迹），不只是前 m 个。
