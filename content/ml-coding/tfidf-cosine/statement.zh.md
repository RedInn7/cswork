# TF-IDF 与余弦相似度

搜索和推荐里常用 TF-IDF 把文档变成向量：一个词在这篇文档里出现得越多、在整个语料里越少见，权重就越大。给定 N 篇已经分好词的文档，不调 sklearn，实现 `tfidf_matrix(docs)`，返回 N×V 的矩阵（V 是不同词的个数，列的顺序随意）：

- tf(t, d)：词 t 在文档 d 里出现的次数。
- df(t)：包含词 t 的文档篇数；idf(t) = ln((1 + N) / (1 + df(t))) + 1（平滑 IDF，和 sklearn 的 `TfidfVectorizer` 默认设置相同）。
- 权重 = tf × idf，然后**每一行除以它的 L2 范数**。

行归一化之后，两篇文档的余弦相似度就是对应两行的点积。驱动代码会算出 Q 对文档的余弦相似度，以及每篇文档向量里最大的分量。

## 输入

第一行是 N 和 Q。接下来 N 行，每行先是词数 L，然后是 L 个词（小写字母组成，可以重复）。再接下来 Q 行，每行两个文档编号 i、j（从 0 开始，可以相同）。

1 ≤ N ≤ 300，1 ≤ L ≤ 50，不同的词不超过 2000 个，1 ≤ Q ≤ 500。

## 输出

驱动代码先输出 Q + N，再输出 Q 个余弦相似度和 N 个最大分量，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

N = 3。the 出现在 3 篇文档里，idf = ln(4/4) + 1 = 1；cat 和 sat 各出现在 2 篇，idf = ln(4/3) + 1 ≈ 1.287682；dog、ate、fish 只出现一次，idf = ln 2 + 1 ≈ 1.693147。第 0 篇是 [1, 1.287682, 1.287682]（the、cat、sat），归一化后是 [0.481334, 0.619805, 0.619805]。它和第 1 篇共有 the 和 sat，余弦约 0.544328。第 2 篇里 the 出现两次，tf = 2。

## 提示

- 先给每个词分配一个列号，统计出 N×V 的词频矩阵，`(counts > 0).sum(axis=0)` 就是每个词的 df。
- 出现在所有文档里的词 idf 是 1 而不是 0：平滑公式里的「+ 1」保证常见词也不会被完全忽略。
- 归一化用 `np.linalg.norm(w, axis=1, keepdims=True)`；题目保证文档不为空，所以范数不会是 0。
