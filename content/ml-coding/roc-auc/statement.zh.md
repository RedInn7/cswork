# ROC-AUC：秩公式与并列分数

二分类模型给每个样本打了一个分数，标签 1 是正类、0 是负类。不调 sklearn，实现 `roc_auc(y, scores)`，返回 ROC 曲线下面积（AUC）。

AUC 等于「随机取一个正样本和一个负样本，正样本分数更高」的概率，分数相同的一对算半个。逐对比较是 O(P·N)，数据大时太慢。用**秩公式**在排序后 O(n log n) 算出来：

- 把全部 n 个分数从小到大排序，排名从 1 开始。**分数相同的一组样本共享它们排名的平均值**，比如第 2、3、4 名分数相同，三个样本的秩都是 3。
- 设正样本有 P 个、负样本有 N 个，R 是所有正样本的秩之和，则 AUC = (R - P(P+1)/2) / (P·N)。

## 输入

第一行是数据组数 T。每组先是一行 n，然后一行 n 个标签（0 或 1），再一行 n 个分数（实数，可能有负数和科学计数法）。每组都保证正负样本至少各有一个。

1 ≤ T ≤ 50，每组 2 ≤ n ≤ 2×10^4，所有组的 n 之和不超过 5×10^4。

## 输出

驱动代码先输出 T，再输出每组的 AUC，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

第一组：正样本分数 0.35 和 0.8，负样本 0.1 和 0.4，四对里 0.35 输给 0.4，其余三对正样本更高，AUC = 3/4。用秩公式：从小到大的秩是 0.1→1、0.35→2、0.4→3、0.8→4，R = 2 + 4 = 6，(6 - 3) / (2·2) = 0.75。

第二组：三个 0.5 排在第 2～4 名，平均秩 3；正样本的秩是 5、3、3，R = 11，AUC = (11 - 6) / (3·2) ≈ 0.833333。逐对算也一样：0.5 对 0.5 的那两对各算半个。

## 提示

- `np.unique(scores, return_inverse=True, return_counts=True)` 给出每个不同分数的出现次数；某组并列的最后一名是计数的前缀和 e，平均秩就是 e - (c - 1)/2。
- 不能直接用 `argsort` 的位置当秩：并列分数会被随便排个先后，AUC 就偏了。
- 秩之和最大约 n²/2，用浮点数或 64 位整数都不会溢出。
