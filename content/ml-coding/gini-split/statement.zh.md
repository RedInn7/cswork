# 决策树桩：Gini 最优切分

决策树每个节点都在找一个「特征 + 阈值」把样本分成两半。给定 n 个样本的 d 个整数特征和类别（0 到 c - 1），不调 sklearn，实现两个函数：

- `gini(y, c)`：Gini 不纯度 1 - Σₖ pₖ²，pₖ 是第 k 类样本的占比。
- `best_split(X, y, c)`：返回 `(特征下标, 阈值, 加权 Gini)`。

候选切分：对每个特征，把它出现过的不同取值排好序，**相邻两个取值的中点**就是一个候选阈值；特征值 **≤ 阈值的样本进左边**，其余进右边。切分的加权 Gini = (n_L / n)·Gini(左) + (n_R / n)·Gini(右)。返回加权 Gini 最小的那个切分。数据保证最优切分唯一，并且至少有一个特征有两种以上的取值。

## 输入

第一行是 n、d、c。接下来 n 行，每行 d 个整数特征和一个类别。

2 ≤ n ≤ 2000，1 ≤ d ≤ 6，2 ≤ c ≤ 4，特征取值在 0 到 10^6 之间。

## 输出

驱动代码先输出 4，再输出整体的 Gini、最优切分的特征下标、阈值和加权 Gini，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

7 个样本里 3 个是 0 类、4 个是 1 类，整体 Gini = 1 - (3/7)² - (4/7)² ≈ 0.489796。按特征 0 在 4.5 处切：左边类别 [0, 0, 1, 0]，Gini = 1 - (3/4)² - (1/4)² = 0.375；右边 [1, 1, 1] 是纯的。加权 Gini = 4/7 × 0.375 ≈ 0.214286。在 2.5 处切是 5/7 × 0.32 ≈ 0.228571，按特征 1 在 4.5 处切约 0.404762，都更差。

## 提示

- 对每个特征按取值排序一次，从左往右扫，维护左边每类的计数（右边 = 总数 - 左边），每个候选阈值 O(c) 就能算出 Gini，总复杂度 O(d·n log n)。
- 只在相邻两个取值**不同**的位置切：取值相同的样本必须分在同一边。
- 加权 Gini 也可以写成 (n_L - Σ L_k²/n_L + n_R - Σ R_k²/n_R) / n，其中 L_k、R_k 是两边各类的样本数，算起来更省事。
