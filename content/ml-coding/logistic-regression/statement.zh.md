# 逻辑回归：梯度下降与 L2 正则

二分类训练集有 n 个样本、d 个特征，标签是 0 或 1。不调 sklearn，实现 `train_logistic(X, y, lr, lam, epochs)`，用**全批量梯度下降**训练逻辑回归，返回 `(w, b)`。

模型是 p = σ(x·w + b)，σ(z) = 1 / (1 + e⁻ᶻ)。损失是平均交叉熵加 L2 正则 (λ/2)·||w||²，**截距 b 不加正则**。严格按下面的步骤，结果才唯一：

1. w 初始化为全 0，b = 0。
2. 重复 epochs 次：用**当前**的 w、b 算出所有样本的 p，令 g = p - y，然后同时更新
   - w ← w - lr·(Xᵀg / n + λ·w)
   - b ← b - lr·mean(g)

驱动代码会用你的 w、b 算出 m 个查询点的正类概率一起输出。

## 输入

第一行是 n、d、m、lr、λ、epochs。接下来 n 行，每行 d 个特征和一个标签；再接下来 m 行，每行一个查询点的 d 个特征。

1 ≤ n ≤ 500，1 ≤ d ≤ 6，1 ≤ m ≤ 100，0 < lr ≤ 1，0 ≤ λ ≤ 2，1 ≤ epochs ≤ 300，特征的绝对值不超过 3。

## 输出

驱动代码先输出数字个数，再输出 w 的 d 个分量、b 和 m 个查询点的概率，保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

x = [0, 1, 2, 3]，y = [0, 0, 1, 1]，lr = 0.5，λ = 0，只走一步。初始所有 p = 0.5，g = [0.5, 0.5, -0.5, -0.5]。Xᵀg / n = (0 + 0.5 - 1 - 1.5) / 4 = -0.5，所以 w = 0 - 0.5·(-0.5) = 0.25；g 的均值是 0，b 不变。查询点 0、2、4 的概率是 σ(0) = 0.5、σ(0.5) ≈ 0.622459、σ(1) ≈ 0.731059。

## 提示

- 一轮更新只需要两次矩阵运算：`X @ w` 和 `X.T @ g`，不用逐个样本循环。
- 先算出两个梯度再一起更新 w 和 b；先改 w 再用新的 w 算 b 的梯度就错了。
- 1 / (1 + np.exp(-z)) 在 z 很负时会溢出报警告；驱动里的写法 0.5·(1 + tanh(z/2)) 和它相等，而且不会溢出。
