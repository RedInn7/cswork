# K 近邻分类

给定 n 个带类别的训练点和 m 个查询点，坐标都是整数。不调 sklearn，实现 `knn_predict(X_train, y_train, X_query, k)`，返回每个查询点的预测类别：

- 距离用**欧氏距离**（比较平方距离即可，顺序一样）。
- 取离查询点最近的 k 个训练点。**距离相同时，训练集里下标小的点算更近。**
- 这 k 个点里出现次数最多的类别就是预测结果。**票数相同时，取编号最小的类别。**

规定好平局怎么处理，答案才唯一：真实面试里也该先问清楚这一点。

## 输入

第一行是 n、m、d、k。接下来 n 行，每行 d 个坐标和一个类别。再接下来 m 行，每行一个查询点的 d 个坐标。

1 ≤ k ≤ n ≤ 2000，1 ≤ m ≤ 300，1 ≤ d ≤ 8，坐标的绝对值不超过 100，类别是 0 到 9 的整数。

## 输出

驱动代码先输出 m，再输出每个查询点的预测类别，保留 6 位小数。

## 样例说明

k = 3。查询点 (0, 0) 最近的是 (0, 0)、(1, 0)、(0, 1)，类别 0、0、1，预测 0。查询点 (5, 4) 最近的三个点类别是 1、2、0，各一票，取最小的 0。查询点 (3, 3) 最近的是 (5, 5)，平方距离 8；接下来 (1, 0)、(0, 1)、(6, 5) 的平方距离都是 13，按下标取 (1, 0)、(0, 1)，三个点的类别是 1、0、1，预测 1。

## 提示

- 广播一次算出所有平方距离：`((Q[:, None, :] - X[None, :, :]) ** 2).sum(axis=2)`，得到 m×n 的矩阵。
- `np.argsort(..., kind='stable')` 在距离相同时保留原来的下标顺序；默认的 quicksort 不保证这一点。
- `np.bincount(labels).argmax()` 返回票数最多的类别，并列时正好是编号最小的那个。
