# 带因果掩码的缩放点积注意力

Transformer 的核心是缩放点积注意力：Attention(Q, K, V) = softmax(QKᵀ / √d_k)·V。给定长度为 T 的序列的查询 Q（T×d_k）、键 K（T×d_k）和值 V（T×d_v），不调 PyTorch，实现 `attention(Q, K, V, causal)`，返回 `(输出, 注意力权重)`：

- 分数 S = QKᵀ / √d_k，是 T×T 矩阵。
- causal 为真时加**因果掩码**：位置 i 只能看到 j ≤ i，j > i 的分数换成 -∞（softmax 后权重为 0）。语言模型解码时不能偷看后面的词，靠的就是它。
- 权重 A = 对 S 逐行做 softmax；输出 = A·V，是 T×d_v 矩阵。

分数可能上千，softmax 要用减去行最大值的稳定写法。

## 输入

第一行是 T、d_k、d_v、causal（1 表示加掩码，0 表示不加）。接下来依次是 Q 的 T 行、K 的 T 行（每行 d_k 个实数）和 V 的 T 行（每行 d_v 个实数）。

1 ≤ T ≤ 64，1 ≤ d_k, d_v ≤ 16，所有数的绝对值不超过 30。

## 输出

驱动代码先输出数字个数，再输出注意力权重（T×T，按行展开）和输出（T×d_v，按行展开），保留 6 位小数。与标准答案的相对或绝对误差不超过 10⁻⁵ 即可。

## 样例说明

d_k = 2，缩放因子 √2。第 0 行只能看自己，权重 [1, 0, 0]，输出就是 V 的第 0 行 [1, 0]。第 1 行的分数是 [0, 1/√2]，softmax 得 [0.330238, 0.669762]，输出 0.330238·[1, 0] + 0.669762·[0, 1]。第 2 行的分数是 [1, 1, 2] / √2，权重 [0.248255, 0.248255, 0.503490]，输出 ≈ [1.255235, 1.255235]。

## 提示

- `np.triu(np.ones((T, T), dtype=bool), k=1)` 正好标出 j > i 的位置，用 `np.where(mask, -np.inf, S)` 把它们换成 -∞。
- 对角线永远不被掩码，所以每行至少有一个有限的分数，减去行最大值后不会出现 -∞ - (-∞) 的 NaN。
- 别忘了除以 √d_k：不缩放时 d_k 越大，分数越大，softmax 越接近 one-hot，梯度也越小。
