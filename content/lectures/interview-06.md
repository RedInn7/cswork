# 树与回溯：子树计算、路径与选择

递归代码往往很短，但短不代表容易证明正确。写递归前先明确：函数收到什么、保证返回什么、调用结束后会不会改变外部状态。树形问题通常把答案从子树向上合并；回溯问题则遍历选择树，在返回上一层时撤销当前选择。

## 树递归的返回值契约

计算树高时，可以约定空树高度为零，每个非空节点返回“一加左右子树高度的较大值”。递归调用本身就是子问题的承诺：不必在父节点里重新展开孙节点，只需要信任相同函数能解决更小的树。

```python
def height(node):
    if node is None:
        return 0
    return 1 + max(height(node.left), height(node.right))
```

如果根节点左侧是一片叶子，右侧还有两层，叶子先返回一，右子树返回二，根返回三。**不变量是每次函数返回时，返回值恰好等于以该节点为根的高度。** 所有节点访问一次，时间 O(n)，递归栈 O(h)，其中 h 为树高；极端链状树中 h 可以等于 n。

Python 在很深的树上可能触发递归深度限制。输入可能很深时，可以改为显式栈或层序遍历。不要为了省事无限提高递归上限，也不要把“平衡树的高度”直接套到没有平衡保证的输入上。

## 回溯：选择、探索、撤销

生成 `[2, 5]` 的所有子集时，每个元素只有“不选”和“选”两条分支。递归深度 i 表示前 i 个元素已经做完决定，path 正好保存其中被选择的元素。到达数组末尾时，把当前路径复制进答案。

| 决策路径 | 到达叶子时的 path |
| --- | --- |
| 不选 2，不选 5 | 空集合 |
| 不选 2，选 5 | 5 |
| 选 2，不选 5 | 2 |
| 选 2，选 5 | 2、5 |

```python
def subsets(values):
    result, path = [], []
    def visit(i):
        if i == len(values):
            result.append(path.copy())
            return
        visit(i + 1)
        path.append(values[i])
        visit(i + 1)
        path.pop()
    visit(0)
    return result
```

关键承诺是：`visit(i)` 返回后，path 必须恢复成进入函数前的样子。少一个 `pop()` 会污染兄弟分支，直接保存 path 而不复制会让多份答案共享同一个可变列表。该函数把输入位置视为不同选择；若输入有重复值且答案要求去重，需要另外处理重复分支。

输出共有 2ⁿ 个子集，复制答案总时间 O(n × 2ⁿ)，答案之外的辅助空间 O(n)。这里不能声称通过技巧把所有子集显式输出的时间降为 O(n)，输出本身就很大。剪枝能排除违反约束的分支，但必须证明被剪掉的分支不可能产生需要的答案。

## 把调用栈展开一次

设根节点为 8，左孩子为 3，右孩子为 10，节点 3 还有一个左孩子 1。调用 `height(8)` 时，程序不会立刻知道结果：它先暂停在根节点，进入 `height(3)`；后者再次暂停，进入 `height(1)`。叶子的两个空孩子分别返回零，因此节点 1 返回一，节点 3 返回二。右子树返回一以后，根节点才能算出三。

| 当前节点 | 左子树返回 | 右子树返回 | 本次返回 |
| --- | --- | --- | --- |
| 1 | 0 | 0 | 1 |
| 3 | 1 | 0 | 2 |
| 10 | 0 | 0 | 1 |
| 8 | 2 | 1 | 3 |

返回顺序是后序：先解决孩子，再处理父节点。前序则是在进入孩子之前处理当前节点，适合复制树、记录根到节点的路径；中序把当前节点放在两棵子树之间，在二叉搜索树中能产生有序序列。遍历顺序应由需要的信息决定。算高度时还没得到孩子的高度，就无法完成父节点的计算。

有时一个返回值不够。判断平衡二叉树既要知道子树高度，也要知道子树是否已经失衡。可以返回二元组；也可以规定高度非负，用负一表示失衡。下面沿用第二种约定，让每个节点只被访问一次。

```python
def is_balanced(root):
    def inspect(node):
        if node is None:
            return 0
        left = inspect(node.left)
        if left == -1:
            return -1
        right = inspect(node.right)
        if right == -1 or abs(left - right) > 1:
            return -1
        return 1 + max(left, right)
    return inspect(root) != -1
```

如果在每个节点先调用一遍 `height`，再递归检查左右孩子，链状树会反复扫描同一段后缀，时间累积到 O(n²)。合并两项计算以后，时间为 O(n)，栈空间仍为 O(h)。这里的负一只在辅助函数内部使用，对外接口仍然返回布尔值。空树也满足平衡条件。

## 全排列为什么需要另一种状态

子集按位置决定选或不选；排列每一层决定“这个位置放谁”。对 `[2,5,7]`，根层有三个选择，下一层只能从剩下两个数里选，最后一层只剩一个。三层共有六个叶子。同一个值可以在不同答案中反复出现，但不能在同一条路径上使用两次，因此访问标记要跟着路径撤销，不能像图遍历那样永久保留。

```python
def permutations(values):
    answer, path = [], []
    used = [False] * len(values)
    def visit():
        if len(path) == len(values):
            answer.append(path.copy())
            return
        for i, value in enumerate(values):
            if used[i]:
                continue
            used[i] = True
            path.append(value)
            visit()
            path.pop()
            used[i] = False
    visit()
    return answer
```

这段程序假设输入元素互不相同；输出时间 O(n × n!)，路径、标记和递归栈合计 O(n)，结果单独占 O(n × n!)。空数组有一个排列，即空排列，返回 `[[]]`。这与“没有合法答案”对应的空列表不同。

若输入为 `[1,1,2]`，两个 1 的位置不同，程序会生成重复排列。需要唯一排列时，先排序，再在同层跳过尚未使用的前一个相同值：`i > 0 and values[i] == values[i-1] and not used[i-1]`。条件中的“前一个未使用”限制的是兄弟分支；前一个已经进入当前路径时，仍然允许选择第二个 1，否则 `[1,1,2]` 这样的合法答案会被删掉。

## 剪枝前，先找出被排除的范围

假设所有候选数都是正数，要找和为目标的组合。当前和已经超过目标，继续添加正数不可能变小，可以停止。若候选数允许负数，这个推理就不成立：当前和 8 超过目标 5，后面选择负 3 仍能得到答案。剪枝条件需要依赖题目约束，不能只根据几个样例猜测。

回溯慢也不一定是缺少剪枝。若请求本来就要输出全部排列，阶乘级输出无法避免；若只问是否存在答案，找到一个后就可以返回，此时不必保存所有路径。只问方案数量时，还可能把具有相同剩余状态的分支合并成记忆化搜索。改变输出要求，往往会改变整个状态设计。

调试时可以在进入递归和返回递归时分别记录 `i`、`path` 和 `used`。同一次调用前后的外部状态应该相同，答案列表除外。只看最终答案很难发现某一层忘记撤销；看一条路径从进入到退出的变化，通常能直接定位错误。

## 树上的路径和，与子树答案不同

若要求找根到叶子的路径，使节点值之和等于目标，可以向下传递“还差多少”：进入节点时减去当前值，到叶子再判断剩余是否为零。这里叶子必须没有左右孩子，不能在任意中间节点恰好凑够时就接受答案，因为题目要求路径走到叶子。负数节点不会破坏这种遍历，但会让“剩余为负就停止”的剪枝失效。

树高只需要返回一个数，路径题需要保存经过的节点；求任意两点之间的最长路径，还可能需要同时维护“向父节点延伸的最佳单条路径”和“在当前节点连接左右两支的完整答案”。父节点只能继续连接一条向下分支，不能把一个已经分叉的路径再向上延伸，否则会得到不合法的 Y 形结构。返回值应该描述父节点真正能使用的结果。

普通二叉树没有环，沿孩子指针递归不必维护全局访问集合；输入如果实际是图，或节点可能共享孩子，就要重新检查这一假设。对无向图沿邻接表递归时，至少要避免立刻走回父节点，存在其他环时还需要访问标记。名字都叫 DFS，不代表状态管理可以完全照抄。
