# 树与回溯：给每一次递归一个明确承诺

递归代码往往很短，但短不代表容易证明正确。写递归前先明确：函数收到什么、保证返回什么、调用结束后会不会改变外部状态。树形问题通常把答案从子树向上合并；回溯问题则遍历选择树，在返回上一层时撤销当前选择。

## 树递归的返回值契约

计算树高时，可以约定空树高度为零，每个非空节点返回“一加左右子树高度的较大值”。递归调用本身就是子问题的承诺：不必在父节点里重新展开孙节点，只需要信任相同函数能解决更小的树。

```python
def height(node):
    if node is None:
        return 0
    return 1 + max(height(node.left), height(node.right))
```

如果根节点左侧是一片叶子，右侧还有两层，叶子先返回一，右子树返回二，根返回三。**不变量是每次函数返回时，返回值恰好等于以该节点为根的高度。** 所有节点访问一次，时间 O(n)，递归栈 O(h)，其中 h 为树高；极端链状树中 h 可以等于 n。

Python 在很深的树上可能触发递归深度限制。面试中应主动说明这一点，必要时改为显式栈或层序遍历。不要为了省事无限提高递归上限，也不要把“平衡树的高度”直接套到没有平衡保证的输入上。

## 回溯：选择、探索、撤销

生成 `[2, 5]` 的所有子集时，每个元素只有“不选”和“选”两条分支。递归深度 i 表示前 i 个元素已经做完决定，path 正好保存其中被选择的元素。到达数组末尾时，把当前路径复制进答案。

| 决策路径 | 到达叶子时的 path |
| --- | --- |
| 不选 2，不选 5 | 空集合 |
| 不选 2，选 5 | 5 |
| 选 2，不选 5 | 2 |
| 选 2，选 5 | 2、5 |

```python
def subsets(values):
    result, path = [], []
    def visit(i):
        if i == len(values):
            result.append(path.copy())
            return
        visit(i + 1)
        path.append(values[i])
        visit(i + 1)
        path.pop()
    visit(0)
    return result
```

关键承诺是：`visit(i)` 返回后，path 必须恢复成进入函数前的样子。少一个 `pop()` 会污染兄弟分支，直接保存 path 而不复制会让多份答案共享同一个可变列表。该函数把输入位置视为不同选择；若输入有重复值且答案要求去重，需要另外处理重复分支。

输出共有 2ⁿ 个子集，复制答案总时间 O(n × 2ⁿ)，答案之外的辅助空间 O(n)。这里不能声称通过技巧把所有子集显式输出的时间降为 O(n)，输出本身就很大。剪枝能排除违反约束的分支，但必须证明被剪掉的分支不可能产生需要的答案。
