# 栈与堆：保留尚未解决的候选

数据结构的价值在于把“下一步最需要谁”变成便宜操作。栈优先处理最近留下的项目，堆优先处理当前最小或最大的项目。二者都能保存候选，但处理顺序不同。面试中不要因为题目出现“最大”就立即选堆，先看候选是否具有可以被永久淘汰的顺序关系。

## 单调栈：等待更大元素

有一组每日观测值 `[4, 2, 5, 3]`，希望知道每个位置要等待多少步，才会遇到严格更大的值。保存尚未找到答案的下标，令栈中对应的值从底到顶单调不增。新值到达时，可以连续解决栈顶那些比它小的位置。

**不变量：栈中的每个位置都还没有在已扫描后缀里遇到更大值。** 当值五使值二和四出栈时，五就是它们右侧第一个更大值，因为此前扫描过的位置都没能解决它们。相等值不能出栈，否则会把“严格更大”误解成“大于等于”。

| 处理值 | 处理前未解决下标 | 本轮解决 | 处理后未解决下标 |
| --- | --- | --- | --- |
| 4 | 空 | 无 | 0 |
| 2 | 0 | 无 | 0、1 |
| 5 | 0、1 | 下标 1 等 1 步；下标 0 等 2 步 | 2 |
| 3 | 2 | 无 | 2、3 |

```python
def steps_until_greater(values):
    answer = [0] * len(values)
    pending = []
    for i, value in enumerate(values):
        while pending and values[pending[-1]] < value:
            old = pending.pop()
            answer[old] = i - old
        pending.append(i)
    return answer
```

每个下标入栈一次、出栈最多一次，因此时间 O(n)，额外空间 O(n)。返回零表示后面没有更大值。若问题要求返回更大元素本身，只需改变记录答案的方式；若要求循环数组，还需要重新设计扫描范围与入栈规则，不能简单拼接答案。

## 堆：流式保留前 K 大

如果输入持续到达，只需保留最大的 k 个值，可以维护大小不超过 k 的最小堆。堆顶是这 k 个候选中最弱的一个，新值只有超过它才值得替换。处理完任意前缀后，堆保存该前缀中最大的至多 k 个值，这就是正确性不变量。

```python
import heapq

def largest_k(values, k):
    if k <= 0:
        return []
    heap = []
    for value in values:
        if len(heap) < k:
            heapq.heappush(heap, value)
        elif value > heap[0]:
            heapq.heapreplace(heap, value)
    return sorted(heap, reverse=True)
```

当 1 ≤ k ≤ n 时，维护时间 O(n log(k + 1))，最后排序 O(k log k)，空间 O(k)。这里保留重复值；如果业务要求不同值，需要额外去重，并重新解释成本。堆不是完整有序数组，除了堆顶，不能假定任意位置都有排序含义。
