# 叠出最高的箱子塔
有 n 个箱子，第 i 个的宽、深、高分别是 w、d、h。箱子不能翻转。叠放时，上面的箱子必须在宽、深、高三个方向上都严格小于下面的箱子。每个箱子最多用一次，问能叠出的塔最高有多高（塔的高度是所用箱子的高度之和）？

## 输入
第一行一个整数 n（1 ≤ n ≤ 1000）。
接下来 n 行，每行三个整数 w、d、h（1 ≤ w, d, h ≤ 10^6）。

## 输出
一个整数，塔的最大高度。

## 样例说明
样例 1 中三个箱子可以依次叠成 (3,3,3) 在下、(2,2,2) 居中、(1,1,1) 在上，总高 6。
样例 2 中 (2,3,4) 不能放在 (2,4,5) 上面：宽相等，不算严格更小。最好的是 (2,4,5) 与 (1,1,1) 组成高 6 的塔，或者 (2,3,4) 与 (1,1,1) 组成高 5 的塔，答案是 6。

## 提示
- 先按宽从大到小排序，这样任何一座合法的塔从下到上都是排序后的一个子序列。再做类似最长递增子序列的 DP：f[i] 是以第 i 个箱子为顶的最高高度。
- 三个方向都要严格小于；只比较宽度、或者把等于也算进去，都会出错。
