# 在单色屏幕上画一条横线
一块单色屏幕宽 w 个像素，每个像素用 1 位表示（1 为亮），整块屏幕按行依次存进一个由 32 位整数组成的数组 screen：每个整数存同一行上连续的 32 个像素，像素的编号越小，存放的位越高（最左边的像素是这个整数的最高位）。数组长度为 length，所以屏幕共有 length·32/w 行。
一开始屏幕全暗。请在第 y 行把第 x1 到第 x2 个像素（包含两端，从 0 开始编号）点亮，然后输出整个数组。整数按 32 位有符号整数输出，最高位为 1 时是负数。

## 输入
一行五个整数 length、w、x1、x2、y。1 ≤ length ≤ 1000，w 是 32 的倍数且 length·32 能被 w 整除，0 ≤ x1 ≤ x2 < w，0 ≤ y < length·32/w。

## 输出
一行 length 个整数，以空格分隔。

## 样例说明
样例 1 中 length = 1、w = 32，在第 0 行点亮第 30、31 号像素，也就是最低的两位，结果是 3。
样例 2 中 length = 3、w = 96，第 0 行横跨三个整数，点亮第 0 到 1 号像素，就是第一个整数的最高两位，按有符号整数是 -1073741824。

## 提示
- 第 y 行第 x 个像素在数组下标 (y·w + x) / 32 处，在这个整数里是从高位数起第 x mod 32 位，也就是第 31 - x mod 32 位。
- 跨越的中间整数整块设成全 1（-1），只需单独处理首尾两个整数的掩码。
