# 按层遍历二叉树
一棵二叉树有 n 个结点，编号为 1 到 n。请从上到下、同一层从左到右地依次输出每个结点的值。

## 输入
第一行两个整数 n 和 root（1 ≤ n ≤ 100000，1 ≤ root ≤ n），表示结点数和根结点的编号。
接下来 n 行，第 i 行三个整数 v、l、r，表示 i 号结点的值为 v（绝对值不超过 10^9），左孩子编号为 l，右孩子编号为 r；没有孩子时写 0。保证输入构成一棵以 root 为根的二叉树。

## 输出
一行 n 个整数，为按层遍历的结果，以空格分隔。

## 样例说明
样例 1 中根是 2 号结点（值 4），它的左孩子 1 号（值 2）、右孩子 4 号（值 7），4 号的两个孩子是 3 号（值 5）和 5 号（值 1）。按层输出就是 4 2 7 5 1。

## 提示
- 用队列：先放入根，每次取出队首结点输出，再把它的左、右孩子依次放到队尾。
- 递归的先序遍历不是按层的顺序。
