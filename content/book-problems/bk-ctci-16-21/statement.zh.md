# 交换一对数让两组的和相等
给定两个整数数组 A 和 B。从 A 中选一个数 a、从 B 中选一个数 b，把它们互换，使两个数组的元素和相等。如果有多种选法，输出 a 最小的那一组，a 相同时 b 也是确定的；如果无法做到，输出 -1。

## 输入
第一行两个整数 n 和 m（1 ≤ n, m ≤ 100000）。
第二行 n 个整数，第三行 m 个整数，都在 -100000 到 100000 之间。

## 输出
可以做到时输出一行 a b，否则输出 -1。

## 样例说明
样例 1 中 A 的和是 14，B 的和是 16。交换 2 和 3 后两边都是 15；交换 7 和 8 也可以，a 最小的是 2 3。
样例 2 中两边的和相差 1，是奇数，怎么换都不行。

## 提示
- 交换后相等，等价于 a - b = (sumA - sumB) / 2。差必须是偶数；把 B 放进哈希集合，枚举 a 查找 b = a - (sumA - sumB)/2 即可。
- 差为奇数时直接无解，不能用整除去近似。
