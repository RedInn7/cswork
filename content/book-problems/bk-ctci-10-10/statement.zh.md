# 数据流中的秩
数字一个接一个地到来。实现两种操作：
track x：记录一个新到的数 x；
rank x：输出到目前为止记录过的数里，小于或等于 x 的有多少个（重复的数按次数计算）。

## 输入
第一行一个整数 q（1 ≤ q ≤ 100000）。
接下来 q 行，每行是 track x 或 rank x（0 ≤ x ≤ 50000）。

## 输出
对每个 rank 操作输出一行结果。

## 样例说明
样例 1 依次记录 5、1、4、4、5、9、7、13、3。rank 1 时只有 1 一个数不超过 1；rank 3 时有 1、3 两个；rank 4 时有 1、3、4、4 四个。

## 提示
- 每次 rank 都遍历一遍是 O(q^2)，太慢。数值范围不大，可以用树状数组按数值计数：track 是单点加一，rank 是前缀和。
- 书中的做法是二叉搜索树，每个结点记下左子树的大小。注意重复的数要按次数计算，而且是“小于或等于”。
