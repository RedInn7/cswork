# 从 1 加到 n
给出若干个询问，每个询问一个正整数 n，请输出 1 + 2 + … + n 的值。
原书的这道题额外要求不用乘除法、不用循环和条件判断来实现，这里不做强制，但你可以挑战一下：比如利用逻辑运算的短路特性来结束递归。

## 输入
第一行一个整数 t（1 ≤ t ≤ 8000）。
第二行 t 个整数 n（1 ≤ n ≤ 10^9）。

## 输出
t 行，每行是对应询问的和。

## 样例说明
1 + 2 + 3 + 4 = 10，1 + 2 + … + 12 = 78。

## 提示
- 公式是 n(n+1)/2。n 最大是 10^9，结果约为 5×10^17，要用 64 位整数，而且要先转成 64 位再相乘。
- 若想挑战原书限制：递归函数里写 n > 1 && (sum = n + f(n-1))，靠短路在 n = 1 时停止；但本题的 n 很大，只能用公式或者位运算模拟乘法。
