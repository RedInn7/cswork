# 一条直线同时平分两个正方形
平面上有两个边与坐标轴平行的正方形，每个用左下角坐标 (x, y) 和边长 size 给出。经过两个正方形中心的直线能把它们都分成面积相等的两半；如果两个中心重合，就取经过中心的竖直线。
这条直线会和两个正方形的边各交于两点。在这四个交点中，取相距最远的两个点，按 x 坐标从小到大输出（x 相同时按 y 从小到大）。

## 输入
两行，每行三个整数 x、y、size，分别描述一个正方形（-1000 ≤ x, y ≤ 1000，1 ≤ size ≤ 1000）。

## 输出
一行：4 x1 y1 x2 y2。4 表示后面有 4 个数，(x1, y1) 和 (x2, y2) 是相距最远的两个交点。与标准答案误差不超过 10^-5 即视为正确（绝对值大于 1 时按相对误差计算）。

## 样例说明
样例 1 中两个正方形的中心分别是 (2, 2) 和 (5, 2)，直线是 y = 2，最远的两个交点是 (1, 2) 和 (6, 2)。
样例 2 中两个中心都是 (5, 5)，取竖直线 x = 5，大正方形上的交点 (5, 3) 和 (5, 7) 相距最远。

## 提示
- 直线与正方形的交点：若直线的斜率绝对值不超过 1，它会穿过正方形的左右两条边，否则穿过上下两条边。竖直线要单独处理。
- 四个交点都在同一条直线上，按沿直线方向的投影排序，最小和最大的两个就是相距最远的点。用分数或者 64 位整数可以避免误差。
