# 翻转一位得到最长的连续 1
给定一个 32 位有符号整数，把它看成 32 个二进制位（负数按补码）。你最多可以把其中一个 0 改成 1，问能得到的最长连续 1 有多长？

## 输入
第一行一个整数 t（1 ≤ t ≤ 10000）。
第二行 t 个整数，每个都在 -2^31 到 2^31 - 1 之间。

## 输出
t 行，每行是对应整数能得到的最长连续 1 的长度。

## 样例说明
1775 的二进制是 11011101111，把第二段和第三段之间的 0 改成 1，得到长度为 8 的连续 1。
7 的二进制是 0…0111，把第 3 位改成 1 得到 4。
-1 的 32 位全是 1，不需要翻转，答案是 32。

## 提示
- 从低位到高位扫描 32 位，记录“当前这段连续 1 的长度”和“上一段的长度”；遇到 0 时，如果下一位是 1，上一段的长度可以和下一段拼起来，否则上一段作废（连续两个 0 无法靠一次翻转连上）。
- 负数只看 32 位补码：右移要用无符号移位，或者先和 0xFFFFFFFF 做与运算。答案不会超过 32。
