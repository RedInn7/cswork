# 倒着读出一条链表
内存里有一条单向链表，共 n 个结点，结点编号为 0 到 n-1。每个结点存了一个整数值和下一个结点的编号，最后一个结点的“下一个”是 -1。结点的描述是乱序给出的，你只知道头结点的编号。
请从尾结点开始，一直到头结点，依次输出每个结点的值。

## 输入
第一行两个整数 n 和 h（1 ≤ n ≤ 15000，0 ≤ h < n），表示结点数和头结点的编号。
接下来 n 行，第 i 行（i 从 0 开始）两个整数 v 和 nx，表示 i 号结点的值为 v（-10^9 ≤ v ≤ 10^9），下一个结点的编号为 nx（nx 为 -1 表示没有下一个结点）。
保证从头结点出发沿着 nx 走，恰好经过所有 n 个结点各一次。

## 输出
一行 n 个整数，从尾结点到头结点依次输出结点的值，以空格分隔。

## 样例说明
样例 1 的链表是 2 号 → 0 号 → 3 号 → 1 号，值依次为 7、5、-2、9，倒过来就是 9 -2 5 7。
样例 2 只有一个结点。

## 提示
- 沿着 nx 走一遍记下顺序，再倒序输出；也可以用栈，或者用递归在“回来”的时候输出。
- 链表很长时，递归可能栈溢出，迭代写法更稳妥。
