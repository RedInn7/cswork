# 井字棋的局面判定
在 N×N 的棋盘上，两名玩家轮流落子，X 和 O 分别是两人的棋子，. 表示空格。某个玩家的棋子占满一整行、一整列或一条对角线（两条对角线都算）时，他就赢了。
给出若干个合法的局面（不会出现两人同时获胜），请判断：有人获胜时输出获胜者 X 或 O；没人获胜且棋盘已满输出 Draw；没人获胜且还有空格输出 Pending。

## 输入
第一行一个整数 t（1 ≤ t ≤ 100）。
接下来每个局面先给出一行整数 N（1 ≤ N ≤ 100），再给出 N 行，每行一个长度为 N 的由 X、O、. 组成的字符串。

## 输出
t 行，每行是对应局面的结果。

## 样例说明
第一个局面中 O 占满了从左上到右下的对角线。
第二个局面棋盘已满且没人连成一线，是 Draw。
第三个局面还有空格，没人获胜，是 Pending。

## 提示
- 分别检查每一行、每一列和两条对角线是否全是同一种棋子（且不是空格）。
- 不要漏掉副对角线（右上到左下）；没人获胜时要看棋盘上还有没有空格，才能区分 Draw 和 Pending。
