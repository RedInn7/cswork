# 合并同义的婴儿名字
统计机构公布了每个名字的使用次数，但有些名字其实是同一个名字的不同拼法。给出若干对“同义名字”，同义关系可以传递（A 与 B 同义、B 与 C 同义，则 A 与 C 同义）。请把同义的名字合并成一组，每组用组内字典序最小的名字作代表，次数为组内所有名字的次数之和。

## 输入
第一行一个整数 n（1 ≤ n ≤ 10000），接下来 n 行，每行一个名字和它的次数（名字由字母组成，长度 1 到 20，互不相同；次数在 0 到 10000 之间）。
接下来一行一个整数 m（0 ≤ m ≤ 10000），再接下来 m 行，每行两个同义的名字，保证都出现在前面的名字列表中。

## 输出
每组输出一行“代表名字 总次数”，按代表名字的字典序（按字符编码比较）从小到大排列。

## 样例说明
样例 1 中 Ana、Anna、Hanna 通过两对同义关系连成一组，代表是字典序最小的 Ana，总次数 7 + 5 + 3 = 15；Beau 和 Bo 一组，代表 Beau，共 2 + 9 = 11；Lin 自成一组。

## 提示
- 用并查集合并同义名字；合并时让字典序更小的名字当根，最后按根累加次数。
- 只处理直接给出的同义对、不考虑传递，会把一条链拆成好几组。
