# 动物收容所
收容所只收猫和狗，严格按“先来先领养”的规则：领养人可以要“最早来的那只动物”（不论猫狗），也可以指定要猫或要狗，这时得到的是最早来的那只猫或那只狗。每只动物有一个编号，编号互不相同，但和到达的先后没有关系。实现以下操作：
enqueue id k：编号为 id 的动物来到收容所，k = 0 表示猫，k = 1 表示狗；
dequeueAny：领走最早来的动物；
dequeueDog：领走最早来的狗；
dequeueCat：领走最早来的猫。
每次领养输出被领走动物的“id k”，没有符合要求的动物时输出 -1 -1。

## 输入
第一行一个整数 q（1 ≤ q ≤ 8000）。
接下来 q 行，每行一个操作，0 ≤ id ≤ 10^9，k 为 0 或 1。

## 输出
对每个领养操作输出一行，两个整数。

## 样例说明
样例 1 中先来的是猫 30，然后是狗 10、狗 20。dequeueAny 领走最早的猫 30；dequeueCat 时已经没有猫，输出 -1 -1；dequeueDog 领走狗 10。

## 提示
- 猫和狗各用一个队列，同时给每只动物记下到达的序号。dequeueAny 比较两个队首谁的序号更小。
- 不要用动物的编号判断先后，编号和到达顺序无关。
