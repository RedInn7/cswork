# 找值等于下标的位置
给定一个按非递减顺序排列的整数数组 a（可能有重复的数），下标从 0 开始。如果 a[i] = i，就称 i 是一个“魔术下标”。请找出最小的魔术下标，不存在时输出 -1。

## 输入
第一行一个整数 n（1 ≤ n ≤ 20000）。
第二行 n 个按非递减顺序排列的整数，绝对值不超过 10^9。

## 输出
一个整数，最小的魔术下标或 -1。

## 样例说明
样例 1 中 a[2] = 2，是唯一的魔术下标。
样例 2 中 a[1] = a[2] = 1，a[1] 满足条件，最小的魔术下标是 1。

## 提示
- 如果数组元素互不相同，可以二分：a[mid] < mid 时答案只可能在右边。
- 有重复元素时二分不再可靠。可以递归搜索左右两半，并利用 a[mid] 跳过不可能的区间：左半边只需看到 min(mid-1, a[mid])，右半边从 max(mid+1, a[mid]) 开始。直接线性扫描也能通过本题。
