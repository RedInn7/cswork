# 一次跨一到三级台阶
小孩上楼梯，每一步可以跨 1 级、2 级或 3 级台阶。上到第 n 级台阶一共有多少种不同的走法？答案可能很大，请输出它除以 1000000007 的余数。有多组询问。

## 输入
第一行一个整数 t（1 ≤ t ≤ 1000）。
第二行 t 个整数 n（1 ≤ n ≤ 1000000）。

## 输出
t 行，每行是对应询问的答案。

## 样例说明
n = 4 时有 7 种走法：1+1+1+1、1+1+2、1+2+1、2+1+1、2+2、1+3、3+1。
n = 6 时有 24 种；n = 1、2 时分别有 1、2 种。

## 提示
- 最后一步跨了 1、2 或 3 级，所以 f(n) = f(n-1) + f(n-2) + f(n-3)，其中 f(1) = 1，f(2) = 2，f(3) = 4。也可以约定 f(0) = 1，表示站在地面上算一种。
- 每一步都取模。询问多时先把答案算到最大的 n，再逐个查表。
