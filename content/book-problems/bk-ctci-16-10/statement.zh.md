# 哪一年活着的人最多
给出 n 个人的出生年份和死亡年份，都在 1900 到 2000 之间。一个人在出生那一年和死亡那一年都算活着。请找出活着的人最多的年份；如果有多个这样的年份，输出最早的那一个。

## 输入
第一行一个整数 n（1 ≤ n ≤ 20000）。
接下来 n 行，每行两个整数 birth 和 death（1900 ≤ birth ≤ death ≤ 2000）。

## 输出
一个整数，活着的人最多的最早年份。

## 样例说明
样例 1 中三个人分别活在 1900–1999、1950–1961、1960–1983。1960 年和 1961 年都有 3 人在世，取较早的 1960。
样例 2 中第一个人在 1910 年去世，那一年仍算活着，所以 1910 年有 2 人在世。

## 提示
- 差分数组：出生年份加一，死亡年份的下一年减一，再从 1900 年开始做前缀和，边求和边记录最大值第一次出现的年份。
- 死亡那一年还算活着，所以减一要放在 death + 1。比较时用严格大于，才能保留最早的年份。
