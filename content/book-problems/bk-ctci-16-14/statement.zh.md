# 穿过最多点的直线
平面上有 n 个互不相同的整数坐标点，按输入顺序编号为 0 到 n-1。找出一条穿过点数最多的直线。设这条直线穿过的所有点的编号从小到大是 S，输出 S[0] 和 S[1]。如果有多条直线穿过的点数一样多，选 S[0] 最小的；S[0] 也相同时选 S[1] 最小的。

## 输入
第一行一个整数 n（2 ≤ n ≤ 300）。
接下来 n 行，每行两个整数 x 和 y（绝对值不超过 10000），所有点互不相同。

## 输出
一行两个整数 S[0] 和 S[1]。

## 样例说明
样例 1 中点 0、1、2 都在直线 y = x 上，穿过 3 个点，没有更多的了。
样例 2 中任意两点确定的直线都只穿过 2 个点，按规则选编号最小的 0 和 1。

## 提示
- 枚举第一个点 i，再看所有编号比 i 大的点 j，按方向 (dx, dy) 分组：用最大公约数约分，并统一符号（例如让 dx > 0，dx 为 0 时让 dy > 0）。同一组里的点和 i 在同一条直线上。
- 用浮点数表示斜率容易出现精度问题，竖直线的斜率还会除以零。
