# 叠罗汉的最多人数
马戏团要叠罗汉：站在上面的人必须比下面的人既矮又轻（身高和体重都严格更小）。给出 n 个人的身高和体重，问最多能叠多少人？

## 输入
第一行一个整数 n（1 ≤ n ≤ 100000）。
接下来 n 行，每行两个整数 h 和 w，表示身高和体重（1 ≤ h, w ≤ 10^6）。

## 输出
一个整数，最多能叠的人数。

## 样例说明
样例 1 中按 (56,90)、(60,95)、(65,100)、(68,110)、(70,150)、(75,190) 从上到下叠，6 个人都能用上。
样例 2 中身高为 2 的两个人身高相同，不能叠在一起，所以最多 2 人。

## 提示
- 按身高从小到大排序，身高相同时按体重从大到小排，再对体重求严格递增的最长子序列。身高相同的人体重倒序，就不会被同时选进一个递增序列。
- 最长递增子序列用“贪心 + 二分”可以做到 O(n log n)。体重相等也不能叠，二分时要找第一个大于或等于当前体重的位置。
