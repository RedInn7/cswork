# 汉诺塔的完整步骤
有 A、B、C 三根柱子，A 上从下到上按从大到小的顺序叠着 n 个盘子。每次只能把某根柱子最上面的一个盘子移到另一根柱子上，任何时候大盘子都不能压在小盘子上。请用最少的步数把所有盘子移到 C 上，并输出每一步。

## 输入
一个整数 n（1 ≤ n ≤ 15）。

## 输出
第一行一个整数 k，表示步数。
接下来 k 行，每行两个字母 x y，表示把 x 柱最上面的盘子移到 y 柱。最少步数的走法是唯一的。

## 样例说明
n = 2 时：先把小盘子从 A 移到 B，再把大盘子从 A 移到 C，最后把小盘子从 B 移到 C，共 3 步。

## 提示
- 要把 n 个盘子从 A 移到 C：先把上面 n-1 个借助 C 移到 B，再把最大的盘子移到 C，最后把 n-1 个借助 A 从 B 移到 C。
- 最少步数是 2^n - 1。
