# 只用加法实现减乘除
原书的题目是：只允许使用加法运算符，实现整数的减法、乘法和除法。这里给出若干个算式，请计算结果；是否只用加法由你自己挑战。
除法的结果向零取整，即舍去小数部分（例如 -7 / 2 = -3，7 / -2 = -3）。

## 输入
第一行一个整数 t（1 ≤ t ≤ 10000）。
接下来 t 行，每行一个算式 a op b，op 是 -、*、/ 之一，a 和 b 是绝对值不超过 10^9 的整数；除法时 b ≠ 0。

## 输出
t 行，每行是对应算式的结果。

## 样例说明
-7 / 2 的精确值是 -3.5，向零取整得 -3。
6 * -4 = -24，5 - -3 = 8。

## 提示
- 减法：a - b = a + (-b)，取相反数可以用不断加 -1 或位运算实现。乘法：把 |b| 拆成 2 的幂之和，对 |a| 做倍增累加，最后决定符号。除法：从大到小尝试 |b| 的 2^k 倍，能减就减。
- 很多语言的整除对负数是向下取整（例如 Python 的 //），和本题的向零取整不同。
