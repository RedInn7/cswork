# 链表倒数第 k 个结点的值
给定一条单向链表和正整数 k，输出倒数第 k 个结点的值。尾结点是倒数第 1 个。

## 输入
第一行两个整数 n 和 k（1 ≤ k ≤ n ≤ 100000）。
第二行 n 个整数，从头到尾依次是每个结点的值，绝对值不超过 10^9。

## 输出
一个整数，倒数第 k 个结点的值。

## 样例说明
链表 1 → 2 → 3 → 4 → 5 的倒数第 2 个结点是 4。

## 提示
- 不知道链表长度时，可以让一个指针先走 k 步，再让两个指针同步前进，前面的指针走到末尾时，后面的指针就停在倒数第 k 个结点上。
- 先数出长度 n，再从头走 n-k 步，也只需要 O(1) 额外空间。
