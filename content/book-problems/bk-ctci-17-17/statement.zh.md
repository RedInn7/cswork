# 在长串里查找多个短串
给定一个长字符串 big 和若干个短字符串，请对每个短串，找出它在 big 中出现的所有起始位置（下标从 0 开始）。不同的出现可以互相重叠。

## 输入
第一行是 big，由小写字母组成，长度 1 到 1000。
第二行一个整数 n（1 ≤ n ≤ 1000）。
第三行 n 个由小写字母组成的短串，长度 1 到 1000，它们的总长度不超过 100000。

## 输出
n 行，第 i 行先输出第 i 个短串的出现次数 k，再从小到大输出它的 k 个起始位置，以空格分隔。

## 样例说明
big 是 abracadabra。abra 出现在 0 和 7；a 出现在 0、3、5、7、10；cad 出现在 4；x 没有出现；bra 出现在 1 和 8。

## 提示
- 把所有短串插入一棵字典树，再从 big 的每个位置出发沿字典树往下走，经过的每个短串结尾都记下一次出现。总时间约为 |big| × 最长短串长度。
- 每找到一次就跳过整个短串长度再找，会漏掉重叠的出现；只找第一次出现也不够。
