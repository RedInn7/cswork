# 不用比较找较大值
给出若干对 32 位有符号整数 a 和 b，输出其中较大的那个。
原书要求不使用 if-else 和任何比较运算符，常见思路是根据 a - b 的符号位来选择。这里不做强制，但要注意：a - b 本身可能超出 32 位整数的范围，符号位就不再可靠了。

## 输入
第一行一个整数 t（1 ≤ t ≤ 100000）。
接下来 t 行，每行两个整数 a 和 b，都在 -2^31 到 2^31 - 1 之间。

## 输出
t 行，每行是对应一对数中较大的那个。

## 样例说明
7 和 -3 中较大的是 7。
2147483647 和 -2147483648 相减会超出 32 位整数，直接看差的符号位会得出错误的结论，正确答案是 2147483647。

## 提示
- 用符号位的写法：k = (a - b) 的符号位，答案为 a·(1-k) + b·k。为了避免溢出，可以先用 64 位整数计算差；或者在 a、b 异号时直接用 a 的符号来决定。
- 公式 (a + b + |a - b|) / 2 也会在 32 位下溢出。
