# 用两种木板拼跳水板
你有很多块长度为 shorter 和长度为 longer 的木板，要把正好 k 块木板首尾相接拼成一块跳水板。请列出跳水板所有可能的长度。

## 输入
一行三个整数 shorter、longer、k（1 ≤ shorter ≤ longer ≤ 100000，0 ≤ k ≤ 100000）。

## 输出
第一行一个整数 m，表示不同长度的个数。
第二行 m 个整数，从小到大列出所有可能的长度，以空格分隔；m 为 0 时这一行为空。

## 样例说明
shorter = 1、longer = 2、k = 3 时，可能的长度是 3、4、5、6。
两种木板一样长时，无论怎么选，长度都只有一种。
k = 0 时一块木板都不用，没有跳水板，所以 m = 0。

## 提示
- 用了 i 块长木板时，长度是 shorter·(k-i) + longer·i，i 从 0 到 k，长度随 i 单调递增。
- 两种长度相等时只有一个结果；k = 0 时没有结果。长度最大约 10^10，需要 64 位整数。
