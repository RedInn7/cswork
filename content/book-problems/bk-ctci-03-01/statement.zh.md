# 一个数组装三个栈
用一个长度为 3c 的数组同时实现 0、1、2 号三个栈，每个栈最多容纳 c 个元素。支持以下操作：
push s v：把 v 压入 s 号栈；如果这个栈已满，忽略这次操作；
pop s：弹出并输出 s 号栈的栈顶，栈空时输出 -1；
peek s：输出 s 号栈的栈顶但不弹出，栈空时输出 -1；
empty s：s 号栈为空时输出 true，否则输出 false。

## 输入
第一行两个整数 c 和 q（1 ≤ c ≤ 1000，1 ≤ q ≤ 100000）。
接下来 q 行，每行一个操作，0 ≤ s ≤ 2，0 ≤ v ≤ 10^9。

## 输出
对每个 pop、peek、empty 操作输出一行结果。

## 样例说明
样例 1 中每个栈只能放 1 个元素，第二次 push 0 2 被忽略，所以 pop 0 弹出 1；之后 0 号栈空了，再弹出得到 -1；1 号栈从未放过元素，empty 1 为 true。

## 提示
- 把数组分成三段，第 s 段是 [s·c, (s+1)·c)，再用三个变量记录每个栈当前的元素个数。
- 每个栈的容量是独立的：一个栈满了，不能借用别的栈的空位。
