# 四条边都是黑色的最大方阵
一个 n×n 的方阵，每个格子是 0（黑）或 1（白）。请找出四条边全由黑色格子组成的最大正方形子方阵（内部不作要求）。输出它左上角的行号、列号（从 0 开始）和边长；有多个最大的时，取行号最小的，行号相同取列号最小的。没有任何黑格时输出 -1。

## 输入
第一行一个整数 n（1 ≤ n ≤ 150）。
接下来 n 行，每行一个长度为 n 的由 0 和 1 组成的字符串。

## 输出
一行三个整数 r c size，或者 -1。

## 样例说明
样例 1 中以 (0,1) 为左上角、边长为 3 的正方形四条边都是 0，中间的 1 不影响；没有更大的。
样例 2 全是白格。

## 提示
- 预处理每个格子向右、向下连续 0 的个数。以 (r, c) 为左上角、边长为 s 的正方形合法，当且仅当左上角向右、向下都至少有 s 个 0，右上角向下、左下角向右也都至少有 s 个 0。
- 枚举左上角，边长从可能的最大值往小试，总时间 O(n^3)。只看外框，不要求内部也全黑。
