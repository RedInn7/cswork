# 用两个栈拼出一个队列
你手里只有“栈”这种数据结构：只能在一端压入和弹出。请用两个栈模拟一个先进先出的队列，支持两种操作：
push x：把整数 x 放到队尾；
pop：取出并输出队首元素；如果队列为空，输出 -1。
依次执行给定的操作。

## 输入
第一行一个整数 q（1 ≤ q ≤ 100000），表示操作个数。
接下来 q 行，每行是 push x（-10^9 ≤ x ≤ 10^9）或 pop。

## 输出
对每个 pop 操作输出一行，为取出的值，或者 -1。

## 样例说明
样例 1 先放入 1、2，取出 1；再放入 3，依次取出 2 和 3；最后队列已空，输出 -1。

## 提示
- 一个栈只管入队，另一个栈只管出队。出队栈空了，再把入队栈里的元素全部倒过去，顺序就反过来了。
- 每个元素最多被倒一次，所以总时间是 O(q)。
