# 在有空位的有序单词表里查词
一张按字典序排好的单词表中散布着一些空位（空位不算单词）。给定一个单词，请找出它在表中的位置（从 0 开始数，空位也占一个位置），不存在时输出 -1。

## 输入
第一行一个整数 n（1 ≤ n ≤ 20000）。
第二行 n 个记号，以空格分隔：每个记号要么是由小写字母组成的单词，要么是一个 #，表示空位。去掉空位后，单词按字典序严格递增（没有重复的单词）。
第三行是要查找的单词，由小写字母组成。

## 输出
一个整数，单词所在的位置，或 -1。

## 样例说明
样例 1 中 cow 位于第 6 个位置（下标从 0 开始，空位也计入）。
样例 2 中表里没有 dog。

## 提示
- 二分查找时，如果中点是空位，就向两侧（或一侧）找到最近的非空位置，再拿那个单词和目标比较。
- 返回的是包含空位在内的位置，不是“第几个单词”。全是空位的区间要能正确结束。
