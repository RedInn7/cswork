# 列出所有不超过 n 位的正整数
给定正整数 n，按从小到大的顺序输出所有位数不超过 n 的正整数，也就是从 1 一直到 n 个 9 组成的那个数。

## 输入
一个整数 n（1 ≤ n ≤ 5）。

## 输出
一行，从 1 开始的所有不超过 n 位的正整数，以空格分隔。

## 样例说明
n = 1 时输出 1 到 9；n = 2 时输出 1 到 99。

## 提示
- 本题的 n 很小，可以直接算出上界 10^n - 1。但如果 n 是几十甚至上百，任何整数类型都放不下，这时要用字符串表示数字：模拟“加一”并处理进位，或者把每一位当作 0 到 9 的全排列来生成，输出时去掉前导零。
- 注意上界是 10^n - 1，不包括 10^n，也不从 0 开始。
