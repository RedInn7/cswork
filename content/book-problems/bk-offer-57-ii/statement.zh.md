# 连续正整数凑出目标和
给定正整数 target，找出所有由至少两个连续正整数组成、总和恰好等于 target 的序列。例如 18 = 3+4+5+6 = 5+6+7。

## 输入
一个整数 target（1 ≤ target ≤ 100000）。

## 输出
第一行一个整数 k，表示序列个数。
接下来 k 行，每行一个序列，从小到大列出其中的数，以空格分隔。各序列按首项从小到大排列。

## 样例说明
样例 1：21 = 1+2+3+4+5+6 = 6+7+8 = 10+11，共三个序列，首项小的在前。
样例 2：4 没有这样的序列，只输出 0。

## 提示
- 滑动窗口：用左右两个端点维护当前连续段的和，和小了右端点右移，和大了左端点右移，相等就记录下来。
- 也可以枚举序列长度 len：首项 = (target - len(len-1)/2) / len，必须是正整数。
