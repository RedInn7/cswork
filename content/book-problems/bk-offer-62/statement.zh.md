# 围成一圈报数，最后剩下谁
n 个人围成一圈，编号依次为 0 到 n-1。从 0 号开始报数，报到 m 的人出圈，下一个人重新从 1 开始报数，如此反复，直到只剩一个人。请问最后剩下的人的编号是多少？
有多组数据。

## 输入
第一行一个整数 t（1 ≤ t ≤ 10）。
接下来 t 行，每行两个整数 n 和 m（1 ≤ n ≤ 100000，1 ≤ m ≤ 10^6）。

## 输出
t 行，每行是对应那组数据最后剩下的编号。

## 样例说明
n = 5、m = 3 时，出圈顺序是 2、0、4、1，最后剩下 3。
n = 10、m = 17 时，最后剩下 2。

## 提示
- 直接模拟删除，每删一次都要在环里数 m 步，太慢。
- 递推：设 f(i) 是 i 个人时最后剩下的编号（从 0 起算），则 f(1) = 0，f(i) = (f(i-1) + m) mod i。注意这里取模用的是当前的人数 i，而不是 n。
