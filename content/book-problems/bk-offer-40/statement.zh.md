# 最小的 k 个数
给定 n 个整数和正整数 k，请找出其中最小的 k 个数，按从小到大的顺序输出。相同的数按出现次数计算，例如 1 出现两次，可以同时出现在答案里。

## 输入
第一行两个整数 n 和 k（1 ≤ k ≤ n ≤ 20000）。
第二行 n 个整数，绝对值不超过 10^9。

## 输出
一行 k 个整数，从小到大排列，以空格分隔。

## 样例说明
样例 1 中最小的两个数是 3 和 4。
样例 2 中 0 出现了两次，最小的三个数是 0 0 3。

## 提示
- 排序后取前 k 个是 O(n log n)。用大小为 k 的大顶堆维护“目前最小的 k 个数”是 O(n log k)；快速选择的平均时间是 O(n)。
- 读入的数要按整数比较，不要按字符串比较（字符串比较下 "10" 小于 "9"）。
