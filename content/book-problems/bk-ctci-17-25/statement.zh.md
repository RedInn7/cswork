# 单词组成的最大矩形
给定一个单词表，请用表里的单词拼出一个字母矩形：每一行从左到右读是表里的一个单词，每一列从上到下读也是表里的一个单词（同一个单词可以用多次；所有行一样长，所有列也一样长）。求这样的矩形面积（行数乘以列数）最大是多少；如果一个都拼不出来，输出 0。

## 输入
第一行一个整数 n（1 ≤ n ≤ 200）。
第二行 n 个互不相同的单词，由小写字母组成，长度 1 到 6。

## 输出
一个整数，最大面积。

## 样例说明
样例 1 中三行 cat / are / ten 的三列从上到下读也是 cat、are、ten，面积为 9；表里没有更长的单词，拼不出更大的矩形。
样例 2 中拼不出任何矩形：只有一行时每列是单个字母，而表里没有单字母的单词；两行 ab / cd 的列 ac、bd 也不在表里。

## 提示
- 按面积从大到小枚举矩形的宽（行单词的长度）和高（列单词的长度），一行一行地回溯填入单词；每填一行，检查每一列目前读出的字母串是不是某个“长度等于高”的单词的前缀，用字典树或前缀集合剪枝。
- 填满之后，每一列必须恰好是一个长度等于高的单词，只是更长单词的前缀不行。正方形之外的长方形也要考虑。
