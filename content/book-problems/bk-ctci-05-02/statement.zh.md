# 小数写成二进制
给定一个介于 0 和 1 之间的实数（以十进制小数形式给出），请写出它的二进制小数表示，形如 0.101。如果它的二进制表示在小数点后 32 位以内不能精确结束，输出 ERROR。

## 输入
一行，一个十进制小数 x，形如 0.625，0 < x < 1，小数点后最多 32 位数字，末尾没有多余的 0。

## 输出
x 的二进制表示（小数点后不超过 32 位，末尾不带多余的 0），或者 ERROR。

## 样例说明
0.625 = 1/2 + 1/8，二进制是 0.101。
0.1 的二进制是无限循环小数 0.0001100110011…，所以输出 ERROR。

## 提示
- 反复乘 2：每次乘完后整数部分是 1 就记下 1 并减去 1，否则记下 0，直到剩下 0。位数超过 32 就失败。
- 浮点数无法精确表示 0.1 这类十进制小数，也可能在乘法中积累误差。最稳妥的是把输入当成分数 p/10^k 用整数来算：能精确结束，当且仅当化简后的分母是 2 的幂，且这个幂不超过 32。
