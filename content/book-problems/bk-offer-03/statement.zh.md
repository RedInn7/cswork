# 找出所有重复的编号
仓库给 n 件货物贴编号，编号只会是 0 到 n-1 之间的整数。录入时出了差错，有的编号被贴在了不止一件货物上（至少有一个这样的编号）。请找出所有被重复使用的编号。

## 输入
第一行一个整数 n（2 ≤ n ≤ 100000）。
第二行 n 个整数，依次是每件货物的编号，每个编号都在 0 到 n-1 之间。保证至少有一个编号出现了两次或更多。

## 输出
一行，按从小到大的顺序输出所有出现次数不少于 2 的编号，以空格分隔，每个编号只输出一次。

## 样例说明
样例 1 中，编号 1 出现了 2 次，编号 4 出现了 3 次，其余编号各出现一次，所以输出 1 4。
样例 2 只有两件货物，编号都是 1。

## 提示
- 编号范围恰好是 0 到 n-1，一个长度为 n 的计数数组就能代替哈希表。
- 想做到额外空间 O(1)：把每个数交换到和它相等的下标上，交换时发现目标位置已经放着同样的数，它就是重复的。
