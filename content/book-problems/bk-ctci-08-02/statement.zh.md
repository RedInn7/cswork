# 机器人绕开障碍走到终点
一个 r 行 c 列的网格，有些格子有障碍。机器人站在左上角，每一步只能向下（D）或向右（R）走一格，不能进入有障碍的格子，目标是走到右下角。
如果能走到，请输出一条走法：一个由 D 和 R 组成、长度为 r+c-2 的字符串；可能的走法有很多，输出其中字典序最小的一条（D 排在 R 前面，也就是能先往下就先往下）。如果走不到，输出 -1。

## 输入
第一行两个整数 r 和 c（1 ≤ r, c ≤ 100）。
接下来 r 行，每行一个长度为 c 的由 0 和 1 组成的字符串，1 表示障碍。

## 输出
一行，字典序最小的走法，或者 -1。起点就是终点时（1 行 1 列且没有障碍），输出一个空行。

## 样例说明
样例 1 中第二行中间有障碍。先往下走一步之后可以一路走到底：DDRR 是字典序最小的走法。
样例 2 中终点被障碍包围，走不到。

## 提示
- 先从终点倒着算出每个格子“能否到达终点”，然后从起点出发，每一步优先往下，只要下面那格能到终点。
- 只顾“能往下就往下”而不检查能否到达终点，会走进死胡同。
