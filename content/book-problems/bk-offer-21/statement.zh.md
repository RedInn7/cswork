# 奇数排在偶数前面
给定一个整数数组，请重新排列：所有奇数放在前半部分，所有偶数放在后半部分。并且奇数之间、偶数之间都要保持原来的先后顺序。
注意负数也有奇偶之分，例如 -3 是奇数，-4 是偶数。

## 输入
第一行一个整数 n（1 ≤ n ≤ 100000）。
第二行 n 个整数，绝对值不超过 10^9。

## 输出
一行 n 个整数，为重新排列后的数组，以空格分隔。

## 样例说明
样例 1 的奇数依次是 1、3、5，偶数依次是 2、4，所以答案是 1 3 5 2 4。
样例 2 中 -3 和 -1 是奇数，保持原顺序排在前面。

## 提示
- 两遍扫描最直接：先收集奇数，再收集偶数。
- 判断奇偶时，很多语言里负数取模得到负数（-3 % 2 等于 -1），写成 x % 2 == 1 会把负奇数当成偶数，可以改用 x % 2 != 0 或位运算 x & 1。
