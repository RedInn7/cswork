# 数字 2 出现了多少次
把 0 到 n 之间的所有整数都写出来（包括 0 和 n），数字 2 一共出现了多少次？例如 22 里有两个 2，要算两次。有多组询问。

## 输入
第一行一个整数 t（1 ≤ t ≤ 10000）。
第二行 t 个整数 n（0 ≤ n ≤ 10^9）。

## 输出
t 行，每行是对应询问的答案。

## 样例说明
0 到 25 中，2 出现在 2、12、20、21、22（两次）、23、24、25 里，一共 9 次。

## 提示
- 逐位计算：对第 k 位（个位、十位……），把 n 拆成高位、当前位和低位。当前位小于 2、等于 2、大于 2 三种情况，分别能算出这一位上 2 出现的次数。
- 直接从 0 数到 n 太慢。注意 n 本身也要算进去。
