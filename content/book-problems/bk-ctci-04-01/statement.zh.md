# 两个结点之间有没有路
给定一张有向图，结点编号为 0 到 n-1，边可能有重复，也可能有自环。判断能否从结点 s 出发、沿着边的方向走到结点 t。s 和 t 相同时视为可以到达。

## 输入
第一行两个整数 n 和 m（1 ≤ n ≤ 10000，0 ≤ m ≤ 10000）。
接下来 m 行，每行两个整数 u 和 v，表示一条从 u 指向 v 的边。
最后一行两个整数 s 和 t。

## 输出
能到达输出 true，否则输出 false。

## 样例说明
样例 1 中有边 0→1、1→2、1→2（重复）、3→3（自环）和 2→0，从 0 出发经过 0→1→2 到达 2，所以输出 true。
样例 2 中只有边 1→0，方向相反，从 0 走不到 1。

## 提示
- 从 s 做 BFS 或 DFS，用 visited 数组避免重复访问，遇到 t 就可以提前结束。
- 边是有方向的，建图时只加 u→v 这一个方向。
