# 从链表里摘掉一个结点
一条单向链表上的结点值互不相同。给定其中一个结点的值 v，请把这个结点从链表中删掉，然后从头到尾输出剩下的链表。

## 输入
第一行一个整数 n（1 ≤ n ≤ 100000），表示结点个数。
第二行 n 个互不相同的整数，从头到尾依次是每个结点的值，绝对值不超过 10^9。
第三行一个整数 v，保证它是某个结点的值。

## 输出
一行，删除之后链表从头到尾的值，以空格分隔。如果链表变空，输出一个空行。

## 样例说明
样例 1 删掉值为 8 的结点，2 直接接到 3 前面。
样例 2 删掉的是头结点 6。

## 提示
- 删除一个结点，就是让它的前一个结点直接指向它的后一个结点。
- 头结点没有“前一个结点”，可以在前面放一个哨兵结点统一处理；删除尾结点和链表只有一个结点的情况也要试一试。
