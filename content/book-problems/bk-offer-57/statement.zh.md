# 有序数组里凑出目标和
给定一个按非递减顺序排列的整数数组和目标值 s，请在数组中找两个不同位置上的数 a 和 b（a ≤ b），使 a + b = s。如果有多组，输出 a 最小的那一组；如果没有，输出 -1。

## 输入
第一行两个整数 n 和 s（2 ≤ n ≤ 100000，1 ≤ s ≤ 2×10^6）。
第二行 n 个按非递减顺序排列的整数，每个在 1 到 10^6 之间。

## 输出
找到时输出一行两个整数 a b；找不到时输出 -1。

## 样例说明
样例 1 中 2 + 7 = 9，也有 4 + 5 = 9，a 最小的是 2 7。
样例 2 中想凑出 6 需要两个 3，但数组里只有一个 3，所以输出 -1。

## 提示
- 双指针：一个从左端出发，一个从右端出发。和太大就把右指针左移，和太小就把左指针右移。可以证明这样找到的第一组就是 a 最小的。
- 同一个位置的数不能用两次。
