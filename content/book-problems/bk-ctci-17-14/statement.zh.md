# 选出最小的 k 个数
给定 n 个整数和非负整数 k，找出其中最小的 k 个数，按从小到大的顺序输出。重复的数按出现次数计算。k 可能为 0。

## 输入
第一行两个整数 n 和 k（1 ≤ n ≤ 100000，0 ≤ k ≤ n）。
第二行 n 个整数，在 0 到 10^9 之间。

## 输出
一行 k 个整数，从小到大排列；k 为 0 时输出一个空行。

## 样例说明
样例 1 中最小的 3 个数是 1、5、5（5 出现了两次）。
样例 2 中 k = 0，什么也不用选。

## 提示
- 快速选择：以某个数为基准把数组分成小于、等于、大于三部分，看第 k 小落在哪一部分，只递归那一部分，平均 O(n)；选出后再对这 k 个数排序。
- 维护一个大小为 k 的大顶堆也可以，注意 k = 0 时堆为空的边界。
