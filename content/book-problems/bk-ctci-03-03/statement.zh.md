# 一摞摞的盘子
盘子叠得太高会倒，所以每摞最多放 cap 个盘子，放满了就另起一摞。把所有摞从左到右编号为 0、1、2……，实现下面的操作：
push v：在最右边那一摞上放一个编号为 v 的盘子；如果没有任何一摞或最右边那摞已满，就在最右边新起一摞；
pop：从最右边那一摞取下最上面的盘子并输出它的编号，没有盘子时输出 -1；
popAt i：从第 i 摞取下最上面的盘子并输出编号，第 i 摞不存在时输出 -1。
任何一摞被取空后都立即撤掉，它右边的各摞编号依次减 1。注意 cap 可能是 0，这时什么都放不上去。

## 输入
第一行两个整数 cap 和 q（0 ≤ cap ≤ 1000，1 ≤ q ≤ 100000）。
接下来 q 行，每行一个操作，0 ≤ v ≤ 10^9，0 ≤ i ≤ 10^5。

## 输出
对每个 pop 和 popAt 操作输出一行结果。

## 样例说明
样例 1 中 cap = 2：放入 5、8、6 后，第 0 摞是 [5, 8]，第 1 摞是 [6]。popAt 0 取出 8；pop 取出 6，第 1 摞空了被撤掉；popAt 0 取出 5，第 0 摞也被撤掉；最后的 pop 已经没有盘子可取，输出 -1。

## 提示
- 用一个“栈的列表”，push 和 pop 只看最后一个栈，popAt 直接访问下标 i。
- 别忘了把取空的摞删掉，否则后面的编号和 pop 的结果都会错；cap 为 0 时 push 什么都不做。
