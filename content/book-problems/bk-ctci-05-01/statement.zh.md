# 把一个数嵌进另一个数的二进制位
给定两个非负整数 N、M 和两个位置 i ≤ j（位从最低位开始编号为 0）。请把 N 的第 i 位到第 j 位替换成 M 的二进制表示：M 的最低位对准第 i 位，N 在这个区间之外的位保持不变。保证 M 恰好能放进 j-i+1 位里。

## 输入
第一行一个整数 t（1 ≤ t ≤ 10000）。
接下来 t 行，每行四个整数 N、M、i、j（0 ≤ N < 2^31，0 ≤ i ≤ j ≤ 30，0 ≤ M < 2^(j-i+1)）。

## 输出
t 行，每行是替换后的 N（十进制）。

## 样例说明
第一组：N = 1000000000（二进制，即 512），M = 101，i = 1，j = 3，结果是 1000001010，即十进制的 522。
第二组：N = 0b11111，M = 0，i = 1，j = 3，第 1~3 位被清零，得到 0b10001 = 17。

## 提示
- 先做一个掩码，第 i 到 j 位是 0、其余位是 1，用它把 N 的这一段清零，再把 M 左移 i 位后按位或进去。
- 只按位或不清零是不够的：N 在这一段原来的 1 会残留下来。
