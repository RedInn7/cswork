# 拼出最小的数
给定若干个非负整数，把它们全部首尾相接拼成一个数字串，每个数恰好用一次、顺序任意。请输出能拼出的字典序最小的数字串（所有结果长度相同，所以也就是数值最小的那个）。前导零保留，不要删除。

## 输入
第一行一个整数 n（1 ≤ n ≤ 100000）。
第二行 n 个整数，每个在 0 到 10^9 之间。

## 输出
一行，拼出的最小数字串。

## 样例说明
样例 1 中 7 和 70 有两种拼法：770 和 707，707 更小，所以 70 要放在 7 前面；75 和 7 比较时 757 小于 775，75 也排在 7 前面。答案是 2707578。
样例 2 拼出 0012，前导零保留。

## 提示
- 对两个数 a、b，如果拼接 ab 小于 ba，a 就应该排在 b 前面。按这个规则排序后依次拼接即可，这个比较规则满足传递性。
- 直接按字符串字典序排序是错的：7 排在 70 前面会得到 770，而 707 更小。
