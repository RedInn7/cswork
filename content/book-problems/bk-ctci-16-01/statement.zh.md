# 不用临时变量的原地交换
原书的题目是：不借助临时变量，交换两个变量的值。常见的写法是异或交换（a ^= b; b ^= a; a ^= b）或加减交换。这里把它放进一个更容易出错的场景：
给定一个长度为 n 的整数数组和 q 次操作，第 k 次操作给出两个位置 i 和 j（从 1 开始编号），交换这两个位置上的数。按顺序执行所有操作后，输出数组。i 和 j 可能相同。

## 输入
第一行两个整数 n 和 q（1 ≤ n, q ≤ 100000）。
第二行 n 个整数，在 0 到 10^9 之间。
接下来 q 行，每行两个整数 i 和 j（1 ≤ i, j ≤ n）。

## 输出
一行 n 个整数，执行完所有交换后的数组。

## 样例说明
样例 1：交换位置 1、3 得到 3 2 1；位置 2、2 是同一个数，交换后不变。
如果用异或交换而 i = j，第一步 a ^= a 就会把这个数变成 0，所以 i = j 时必须跳过。

## 提示
- 用异或或加减来交换时，两个“变量”实际上是同一块内存的情况要特别处理。
- 位置从 1 开始编号，注意和数组下标的换算。
