# 两条线段的交点
平面上有两条线段，每条由两个不同的整数坐标端点给出。如果它们有公共点，输出交点；如果公共点不止一个（两条线段共线且部分重合），输出其中 x 坐标最小的点，x 相同时取 y 坐标最小的点。没有公共点时输出 0。

## 输入
第一行四个整数 x1 y1 x2 y2，表示第一条线段的两个端点。
第二行四个整数 x3 y3 x4 y4，表示第二条线段的两个端点。
所有坐标的绝对值不超过 10^6，同一条线段的两个端点不重合。

## 输出
没有公共点时输出 0。否则输出一行 2 x y，其中 2 表示后面有两个数，x 和 y 是交点坐标。与标准答案误差不超过 10^-5 即视为正确（坐标绝对值大于 1 时按相对误差计算）。

## 样例说明
样例 1 中线段 (0,0)-(1,0) 与 (1,1)-(0,-1) 相交于 (0.5, 0)。
样例 2 中两条线段都在直线 y = x 上，重合部分是 (1,1) 到 (2,2)，取 x 最小的 (1,1)。

## 提示
- 用叉积求参数：设交点为 P1 + t(P2 - P1) = P3 + u(P4 - P3)，两个参数都在 [0, 1] 内才算交在线段上，而不是交在延长线上。
- 叉积为 0 时两条线段平行；如果还共线，就检查四个端点中哪些同时落在两条线段上，从中挑出 x 最小（再比 y）的那个。
