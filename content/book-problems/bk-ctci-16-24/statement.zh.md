# 尽可能多的和为目标值的数对
给定一个整数数组和目标值 target，把数组里的数两两配对，每个数最多用一次，要求每一对的和都等于 target。请找出最多能配成多少对，并列出这些数对。

## 输入
第一行两个整数 n 和 target（1 ≤ n ≤ 100000，绝对值不超过 10^9）。
第二行 n 个整数，绝对值不超过 10^9。

## 输出
第一行一个整数 k，表示最多的对数。
接下来 k 行，每行一对数 x y（x ≤ y），所有数对按 x 从小到大排列（x 相同时按 y）。在对数最多的前提下，配出的数对构成的集合是唯一的。

## 样例说明
样例 1 中 5 和 7 配成两对（5 出现两次、7 出现两次），6 和 6 配成一对，答案是 3 对。
样例 2 中只有一个 3，凑不成 3+3。

## 提示
- 用哈希表计数：对每个值 x，能配的对数是 min(cnt[x], cnt[target-x])；x 恰好等于 target-x 时是 cnt[x] / 2。
- 也可以排序后用双指针从两端向中间配对。
