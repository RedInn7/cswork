# 能随时报出最大值的队列
实现一个整数队列，支持三种操作：
push x：把 x 放到队尾；
pop：取出并输出队首元素，队列为空时输出 -1；
max：输出队列中当前的最大值，队列为空时输出 -1。
请依次执行给定的操作，每个操作的均摊时间应为 O(1)。

## 输入
第一行一个整数 q（1 ≤ q ≤ 100000）。
接下来 q 行，每行是 push x（1 ≤ x ≤ 10^9）、pop 或 max 中的一种。

## 输出
对每个 pop 和 max 操作输出一行结果。

## 样例说明
样例 1 先放入 4、6、3，最大值是 6；取出 4 后最大值还是 6；再取出 6，队列里只剩 3，最大值变成 3。

## 提示
- 另外维护一个双端队列，里面的值从队首到队尾单调不增：放入 x 时，先把末尾比 x 小的都删掉。它的队首就是最大值。
- 弹出元素时，如果它等于辅助队列的队首，就把辅助队列的队首也弹出。所以放入时只能删掉严格更小的值，相等的值要保留。
