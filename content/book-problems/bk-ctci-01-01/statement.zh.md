# 字符各不相同吗
给出若干个字符串，判断每个字符串里的字符是否互不相同（大小写不同的字母算不同字符）。

## 输入
第一行一个整数 t（1 ≤ t ≤ 1000）。
接下来 t 行，每行一个字符串，长度在 1 到 100 之间，由 ASCII 码 33 到 126 的可见字符组成（不含空格）。

## 输出
t 行，每行输出 true 或 false：字符互不相同时输出 true。

## 样例说明
banana 里 a 和 n 都重复了，所以是 false；xyz 和 aA1! 的字符都不重复，都是 true。

## 提示
- 用一个大小为 128 的布尔数组记录见过的字符，见到重复就停。
- 想不用额外的数据结构，可以先排序再比较相邻字符。用整数做位图时注意：可见字符有 94 种，32 位整数放不下，在很多语言里 1 << 40 会悄悄变成 1 << 8。
