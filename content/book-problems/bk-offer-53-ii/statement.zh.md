# 少了哪个编号
0 到 n 这 n+1 个整数里恰好少了一个，剩下的 n 个按从小到大的顺序排成一个数组。请找出少掉的那个数。

## 输入
第一行一个整数 n（1 ≤ n ≤ 30000）。
第二行 n 个严格递增的整数，都在 0 到 n 之间。

## 输出
一个整数，被去掉的那个数。

## 样例说明
样例 1 是 0 1 2 4 5，少了 3。
样例 2 是 0 1 2，少的是最后一个数 3。

## 提示
- 少掉的数之前，每个位置的值都等于下标；从它开始，值都比下标大 1。用二分查找第一个“值不等于下标”的位置，时间 O(log n)。
- 别忘了少掉的可能是 0，也可能是 n。
