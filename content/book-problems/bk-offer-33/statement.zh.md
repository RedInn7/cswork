# 检验二叉搜索树的后序序列
二叉搜索树中，每个结点左子树的值都比它小，右子树的值都比它大。后序遍历按“左子树、右子树、根”的顺序访问结点。
给定一个各元素互不相同的整数序列，判断它是否可能是某棵二叉搜索树的后序遍历结果。

## 输入
第一行一个整数 t（1 ≤ t ≤ 10），表示序列个数。
接下来每个序列占两行：第一行是长度 n（1 ≤ n ≤ 2000），第二行是 n 个互不相同的整数，绝对值不超过 10^9。

## 输出
t 行，每行输出 true 或 false。

## 样例说明
第一个序列 1 3 2 6 5 是以 5 为根、左子树 {1, 3, 2}、右子树 {6} 的树的后序遍历，所以是 true。
第二个序列 1 6 3 2 5：根是 5，从左往右第一个比 5 大的是 6，所以左子树只有 {1}，右子树是 {6, 3, 2}，但 3 和 2 比根小，不可能在右子树里，所以是 false。

## 提示
- 最后一个数是根。从左往右找到第一个比根大的位置，前面是左子树、后面到根之前是右子树；右子树里不能出现比根小的数。然后对两部分递归检查。
- 也可以用单调栈在 O(n) 时间内倒着扫描完成。
