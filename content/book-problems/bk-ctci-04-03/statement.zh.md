# 二叉树每一层的结点
一棵二叉树有 n 个结点，编号为 1 到 n。请把每一层的结点值按从左到右的顺序列出来，从根所在的第一层开始。

## 输入
第一行两个整数 n 和 root（1 ≤ n ≤ 10000，1 ≤ root ≤ n）。
接下来 n 行，第 i 行三个整数 v、l、r：i 号结点的值为 v（绝对值不超过 10^9），左孩子编号为 l，右孩子编号为 r，没有孩子时写 0。

## 输出
第一行一个整数 d，表示树的层数。
接下来 d 行，第 i 行先输出第 i 层的结点个数 k，再从左到右输出这一层的 k 个结点值，以空格分隔。

## 样例说明
样例 1 的根是 1 号结点（值 10），第二层是 20、30，第三层是 40、50、60，第四层是 70。

## 提示
- 按层 BFS：每一轮先记下队列当前的长度，这么多个结点就是同一层，处理完再进入下一层。
- 也可以 DFS 时带上深度，把结点追加到对应深度的列表里；只要先访问左孩子，同层顺序就是从左到右。
