# 稀疏文档的相似度
有 n 篇文档，编号 0 到 n-1，每篇文档是一组互不相同的整数（可以理解为其中出现的词的编号）。两篇文档的相似度定义为：两组整数的交集大小除以并集大小。请找出所有相似度大于 0 的文档对，输出它们的相似度。
为了避免浮点误差，相似度用最简分数 p/q 表示。

## 输入
第一行一个整数 n（1 ≤ n ≤ 500）。
接下来 n 行，第 i 行先是文档 i 的整数个数 k（1 ≤ k ≤ 500），再是 k 个互不相同的整数（0 到 10^5 之间）。所有文档的整数总数不超过 50000。

## 输出
第一行一个整数 c，表示相似度大于 0 的文档对的个数。
接下来 c 行，每行 i j p/q（i < j），按 i 从小到大、i 相同按 j 从小到大排列。

## 样例说明
样例 1 中文档 0 = {1, 2, 3}，文档 1 = {2, 3, 4, 5}，交集 {2, 3}，并集 {1, 2, 3, 4, 5}，相似度 2/5；文档 0 与文档 2 = {3, 9} 交于 {3}，并集有 4 个数，相似度 1/4；文档 1 与文档 2 交于 {3}，并集 5 个数，相似度 1/5；文档 3 = {7} 与谁都不相交。

## 提示
- 文档多而每篇很稀疏时，两两求交集很浪费。建立倒排表：对每个整数记下包含它的文档，再对每个整数，把列表里的文档两两计数，就得到每对文档的交集大小；并集大小 = |A| + |B| - 交集。
- 用最大公约数把分数化简。并集要减去交集，不然算出来的是交集除以两边大小之和。
