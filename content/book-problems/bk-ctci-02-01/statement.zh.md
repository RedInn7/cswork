# 链表去重，保留第一次出现
给定一条未排序的单向链表，删除所有重复的值：每个值只保留它第一次出现的那个结点，其余结点的相对顺序不变。输出处理后的链表。

## 输入
第一行一个整数 n（1 ≤ n ≤ 100000）。
第二行 n 个整数，从头到尾依次是每个结点的值，绝对值不超过 10^9。

## 输出
一行，去重后链表从头到尾的值，以空格分隔。

## 样例说明
样例 1 中第二个 3 和第二个 1 都是重复的，删掉后是 1 2 3。
样例 2 中所有值相同，只剩第一个结点。

## 提示
- 用哈希集合记录已经出现过的值，遍历时把重复的结点从链表上摘掉（让前一个结点跳过它）。
- 如果不允许额外空间，可以对每个结点再向后扫一遍删掉相同的值，时间是 O(n^2)。注意重复的值不一定挨在一起。
