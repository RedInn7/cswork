# 池塘的大小
一块 r 行 c 列的土地，每个格子上的整数表示海拔，海拔为 0 的格子是水。水格子在上下左右以及四个对角方向上相连，连在一起的水构成一个池塘，池塘的大小是其中水格子的个数。请按从小到大的顺序输出所有池塘的大小。

## 输入
第一行两个整数 r 和 c（1 ≤ r, c ≤ 500）。
接下来 r 行，每行 c 个整数，在 0 到 9 之间。

## 输出
第一行一个整数 k，表示池塘的个数。
第二行 k 个整数，从小到大列出各池塘的大小；k 为 0 时这一行为空。

## 样例说明
用 (行, 列) 表示格子，从 0 开始编号。样例 1 中 (0,1) 和 (0,2) 左右相邻，(1,0)、(2,1)、(1,3) 都经由对角线与它们连在一起，这 5 个格子组成一个池塘；右下角的 (3,3) 单独成为一个池塘。所以答案是 1 5。

## 提示
- 遍历每个格子，遇到没访问过的水格子，就从它出发做 BFS 或 DFS，把 8 个方向上相邻的水格子都标记掉，并统计个数。
- 只看上下左右会把斜着相连的池塘拆开。网格较大时递归 DFS 可能栈溢出，可以改用显式栈或队列。
