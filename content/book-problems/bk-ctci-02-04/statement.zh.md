# 按基准值把链表分成两段
给定一条单向链表和基准值 x，重新排列链表：所有值小于 x 的结点排在前面，值大于或等于 x 的结点排在后面。两部分内部都要保持结点原来的先后顺序。

## 输入
第一行两个整数 n 和 x（1 ≤ n ≤ 100000，绝对值不超过 10^9）。
第二行 n 个整数，从头到尾依次是每个结点的值，绝对值不超过 10^9。

## 输出
一行 n 个整数，重排后链表从头到尾的值，以空格分隔。

## 样例说明
x = 5 时，小于 5 的结点依次是 1、2、3，其余依次是 6、5、9、5，所以结果是 1 2 3 6 5 9 5。注意等于 5 的结点属于后半段。

## 提示
- 建两条新链表（各带一个哨兵头结点），遍历原链表时把结点分别接到它们的尾部，最后把两条首尾相连。
- 每次把小结点插到表头虽然也能分开两部分，但会把它们的顺序颠倒。
