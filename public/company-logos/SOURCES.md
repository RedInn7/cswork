# Additional company logo sources

Logos added after the Simple Icons 16.30.0 set listed in [README.md](README.md). Every entry is an official brand logo taken from an openly licensed, traceable source:

1. [gilbarbara/logos](https://github.com/gilbarbara/logos) (CC0-1.0), pinned to commit `37a6b807fd71c622efea27a9309b5d4edc792969`.
2. [Simple Icons](https://github.com/simple-icons/simple-icons) npm release 16.34.0 (CC0-1.0, license in LICENSE.simple-icons.md).
3. Wikimedia Commons files marked public domain (e.g. {{PD-textlogo}}); each license tag was checked on the file page.

Logos only identify OA company categories and imply no affiliation or endorsement. Trademark rights remain with the brand owners.

Processing (same for every file): XML prolog, comments, titles and editor metadata removed; `<style>` class rules inlined as `style` attributes; internal `<use>` references expanded; the original drawing is wrapped unchanged in a nested `<svg>` so the file has `viewBox="0 0 24 24"`. Shapes and colors are not changed except where a fill is noted.

Companies without a reliable openly licensed logo keep their text initials.
